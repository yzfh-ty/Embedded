# 命令

什么是命令：命令就是一个有特定功能程序。

## 命令的种类：

1. 内部命令（在Shell 内定义的命令）
    
    - 如： cd 、pwd

2. 外部命令（对应一个单独的文件）：
    
    - 如：tree。

## 命令的格式

```shell
命令 [选项]...  [参数]...
```

说明格式说明:

- 命令、选项或参数要用一个或多个空白字符（空格、制表符等人）分隔。
    
- 选项通常以 一个或两个减号开头，通常选项由命令提供，命令根据选项做不同的事情。
    
    - 如: `ls -l -a`
- 参数通常是为命令提供的数据。
    
大多数的命令参数可以写在命令的任意位置

例如：下面这两句都是正确的，但是大多数情况下我们会将参数放在命令的后面，路径或是文件放在最后面

```
ls -la /home/yzfh
ls /home/yzfh -la
```

## 查看 Linux 下所有可用的Shell

```shell
cat /etc/shells
/bin/sh
/bin/bash
/usr/bin/bash
/bin/rbash
/usr/bin/rbash
/bin/dash
/usr/bin/dash
```

切换Shell

```shell
# 切换使用 /bin/sh
/bin/sh
# 切换使用 /bin/bash
/bin/bash
# 退出 bash,回到 sh
exit
```

## 通配符

作用：在终端内，用来匹配文件或文件夹列表。

1. 星号( _*_ )：匹配零个、一个或多个任意字符。
2. 问号( _?_ )：匹配一个任意字符。
