## sudo 命令

作用： 用于使用 root（超级用户） 权限执行命令或切换到 root 用户登录。

命令格式

```shell
sudo 命令 [选项或参数]...
```

常用选项

|选项|说明|
|---|---|
|-i|切换到 root 用户|

## su 命令

作用：用于切换用户登录

命令格式

```shell
su 用户名
```

示例：

```shell
su zhang3  # 在Shell 内用张三用户登录。
```

> 默认输入`su` 切换到 root 用户

练习：

创建 lisi 账户，修改密码，登录。然后删除此账户。
