# 系统退出命令

### exit

作用：用于退出用户登录（或离开当前终端）

```shell
exit
```

### reboot

作用： 重启系统

```shell
sudo reboot
```

## shutdown

关机命令，默认一分钟以后关机

```shell
sudo shutdown

# 立刻关机
sudo shutdown -h now
```
