# 根下文件夹的作用：

1. /root 超级用户的文件夹。
2. /home 用户主文件夹相关的文件夹
3. /dev 硬件设备相关的文件夹，内部都是硬件设备。
4. /media 自动挂载文件系统的文件夹。
5. /mnt 手动挂载文件系统的文件夹。
6. /bin. 存放可执行程序的文件夹
7. /sbin 存放系统可执行程序的文件夹
8. /usr. Unix System Resource （存放 UNIX 命令名的文件夹）
9. /var. 存放常改变的文件的文件夹。
10. /tmp. 用于存放临时文件的文件夹.
11. /etc. 存放配置文件的文件夹
12. /opt. 存放第三方软件的文件夹 。
13. /proc 系统运行文件相关的文件夹。
14. /boot Linux 内核启动相关的文件。
15. /etc/passwd 文件是用来保存 Linux 用户信息的重要文件。

# 路径

什么是路径：路径用于描述一个文件或文件夹位置的字符串。

路径的分类：

1. 绝对路径：是从根开始的路径，第一个字符一定斜杠 `/`
2. 相对路径：通常用于表示相对于某个文件夹的路径，第一个字符不是斜杠。

> UNIX/Linux 路径的分隔符是斜杠 `/`
> 
> Windows 路径的分隔符是反斜杠 `\`

路径的特殊字符

- `~` 表示当前用户的主目录(主文件夹，只能在 Shell 内部使用）
- `.` 表示当前文件夹。
- `..` 表示上一节文件夹。

路径通配符

- `*` 匹配0个、1个或多个任意字符
- `?` 匹配1个任意字符

> Linux系统下可以使用 *~* 表示家路径
> 例如： 用户 yzfh ，则 *~* 表示的路径为 */home/yzfh*

# 文件的详细信息

    
- 第一列第一个字符表示文件的类型
    
    - d 表示文件夹
    - - 表示普通文件
    - l 表示链接文件
    - b 表示块设备文件
    - c 表示字符设备文件
    - s 表示套接字文件。
    - p 表示管道文件。
- 第一列第2个10字符表示文件的权限
    
    - 权限位(bit)
        
        - r 读权限
        - w 写权限
        - x 执行权限
            - 对于普通文件指是否可以运行
            - 对于文件夹指是否能够进入内部。
        - - 没有这个权限
    - 共三组（9个bit）
        
        - 用户的权限（3个bit: rwx)
        - 组的权限（3个bit: rwx)
        - 其他的权限（3个bit: rwx)
    - 第二列 表示此文件或文件夹应用的次数
        
    - 第三列 表示此文件或文件夹用户（属主）是谁。
        
    - 第四列 表示此文件或文件夹组（属组）是那个组。
        
    - 第五列 表示此文件或文件夹组所占用的存储空间。
        
    - 第六、七、八列 表示此文件或文件夹的创建时间。
        
    - 第九列 表示此文件或文件夹组的名称。

## 文件有两部分组成

1. 索引节点（iNode）用来存放文件名，文件权限及创建时间等信息。
2. 内容部分。

# /etc/passwd 文件说明

冒号分隔多列

- 第一列：用户名
- 第二列：x 代表有密码
- 第三列：用户ID ，整数（0~999为系统用户，1000以上为普通用户)
- 第四列：组ID
- 第五列：用户别名
- 第六列：用户家目录（家文件夹）
- 第七列：此用户使用的Shell
