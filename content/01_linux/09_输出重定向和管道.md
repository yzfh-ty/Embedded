## 输出重定向

- Linux 系统终端下三个重要的Input/Output。
    - 标准输入（默认是键盘）
    - 标准输出（默认是终端）
    - 标准错误输出（默认是终端）

语法

```shell
# 标准输出重定向到文件
命令 > 文件 
# 标准错误输出重定向到文件
命令 2> 文件 
```

示例

```shell
find /etc -name "source*" > r.txt
find /etc -name "source*" 2> error.txt
find /etc -name "source*" > r.txt 2> error.txt
```

黑洞文件：`/dev/null`

向此文件内写入任何内容都会被丢弃。

## 管道

管道运算符 `|` 是将一个程序（或命令的输出）作为另外命令的输入的一个程序组。

管道的格式

```shell
命令1 [选项或参数] | 命令2 [选项或参数]
```

如：

```shell
ls --help | more
```
