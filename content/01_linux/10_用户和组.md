# 用户（User）和组（Group）


组是批量管理用户权限的工具。

组相关的文件: _/etc/group_

### groupadd 命令

作用：添加组

命令格式:

```shell
groupadd [选项] 组名
```

示例

```shell
# 创建嵌入式3班组
sudo groupadd emb3
```

### groupdel 命令

作用：删除组

命令格式:

```shell
groupdel [选项] 组名
```

常用选项：

- -f 强制删除:即便是用户的主组也继续删除。

示例

```shell
# 创建嵌入式3班组
sudo groupdel emb3
```

### groups 命令

作用：显示当前用户在哪些组中。

### useradd命令

作用：创建新用户

命令格式

```
useradd [选项] 用户名
```

常用选项

|     选项      |                   说明                    |
| :---------: | :-------------------------------------: |
|     -m      |         创建用户主目录（通常与 *-k* 一起使用）          |
|   -s <路径>   |              指定用户登录 Shell               |
|   -c <别名>   |              为用户添加备注/描述信息               |
|   -d <路径>   |                指定用户主目录路径                |
| -g <组名或组ID> |              指定用户主组的组ID或组名              |
| -G <组名或组ID> |          指定用户附加组的组ID或组名（逗号分隔）           |
|     -r      |          创建系统账户（无主目录，UID<1000）          |
|   -k <路径>   | 指定骨架文件夹（与`-m`一起使用），默认会把骨架文件夹的内容复制到用户主目录 |

示例:

```shell
# 创建一个名字为: zhang3 的用户。
sudo useradd zhang3
# 创建一个名字为: zhang3 的用户。
# 创建家目录，并指定家目录的框架是 /etc/skel# 指定其主组是 emb3、别名是 zhangwuji。
# 指定 Shell 是 /bin/bash。让其加入 root、sudo 组
sudo useradd -m -k /etc/skel -g emb3 -G root,sudo -c zhangwuji -s /bin/bash zhang3 
```

### userdel 命令

作用：删除用户账户。

命令格式

```shell
userdel [选项] [用户名]
```

常用选项

| 选项  | 说明                                  |
| --- | ----------------------------------- |
| -r  | 删除用户的同时，删除其主目录和邮件池（推荐使用）。           |
| -f  | 强制删除用户，即使该用户仍处于登录状态或存在未退出的进程（谨慎使用）。 |

示例

```shell
sudo userdel -r zhang3
```

### passwd 命令：

作用：用于修改某个用户的密码

命令格式

```shell
passwd [选项] [用户名]
```

> 没有用户名，默认修改自己的密码。

### usermod 命令

作用：用来修改用户的属性

命令格式:

```shell
usermod [选项] 用户名
```

> 选项见 *usermod --help*
