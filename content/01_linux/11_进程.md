# 进程管理命令

什么是进程：进程是正在运行的程序

### ps 命令

作用：查看当前进程

常用选项：

| 选项   | 说明          |
| ---- | ----------- |
| -aux | 查看所有进程      |
| -ejH | 缩进现实进程的树形关系 |

*-aux* 列说明：
- USER 进程的启动者（拥有者）
- PID 进程的ID（从零开始依次递增）
- TTY 进程使用的终端
- TIME 进程使用的时间
- CMD 运行的命令
- %CPU CPU 占比
- %MEM 内存的占比
- VSZ 虚拟内存的大小
- RSS 真实内存占用大小
- STAT 进程状态
    - R 表示正在运行的进程（运行态）
    - S 表示睡眠的进程（就绪态的进程）
    - D 不可中断的睡眠进程。
    - T 表示停止态经常
    - Z 表示僵尸进程。
    - I 内核进程（Idle 闲置状态）
- START 进程启动时间
- TIME 累积占用 CPU时间

### pstree 命令

作用：以树形结构显示进程

常用选项:

- *-p* 显示 PID。

示例

```shell
pstree -p
```

### kill 命令

作用：给进程发信号，通常用于退出进程。

命令格式

```shell
kill 选项 进程号(PID)
```

常用选项

| 选项      | 说明               |
| ------- | ---------------- |
| -l      | 列出所有信号。          |
| -n      | 发送指定值的信号(n=1~64) |
| -s <名称> | 根据名称发送指定值的信号。    |

示例

```shell
kill -9 6666   # 退出 PID 为 6666 的进程
```

### systemctl 命令

作用：管理各种运行于后台的服务

常用的命令格式

```shell
# 查看所有的服务（包括未运行的服务）
systemctl 

# 查看特定的服务的状态
systemctl status ssh.service

# 停止服务
systemctl stop ssh.service

# 启动服务
systemctl start ssh.service

# 重新启动服务s
ystemctl restart ssh.service

# 设置开机启动服务
systemctl enable ssh.service

# 禁止开机启动服务
systemctl disable ssh.service

# 查看是否设置开机启动服务
systemctl is-enabled ssh.service
```
