# printf函数

作用：打印字符数据到标准输出。

头文件：*# include <stdio.h>*

调用格式:

```c
printf("格式化字符串", 表达式1, 表达式2, ...);
```

格式化字符串的占位符和类型码

| 占位符         | 作用                            | 示例代码                                                     | 示例输出                             |
| ----------- | ----------------------------- | -------------------------------------------------------- | -------------------------------- |
| `%d` 或 `%i` | 输出有符号的十进制整数                   | `printf("%d\n", 123);`<br>`printf("%d\n", -123);`        | `123`<br>`-123`                  |
| `%u`        | 输出无符号的十进制整数                   | `printf("%u\n", 123);`<br>`printf("%u\n", -123);`        | `123`<br>`4294967173`（32 位系统）    |
| `%o`        | 输出无符号的八进制整数                   | `printf("%o\n", 255);`                                   | `377`                            |
| `%x` 或 `%X` | 输出无符号的十六进制整数（小写或大写）           | `printf("%x\n", 255);`<br>`printf("%X\n", 255);`         | `ff`<br>`FF`                     |
| `%f`        | 输出浮点数（小数形式）                   | `printf("%f\n", 3.14159);`                               | `3.141590`                       |
| `%e` 或 `%E` | 输出浮点数（科学计数法，小写或大写）            | `printf("%e\n", 3.14159);`<br>`printf("%E\n", 3.14159);` | `3.141590e+00`<br>`3.141590E+00` |
| `%g` 或 `%G` | 根据数值大小自动选择 `%f` 或 `%e`（小写或大写） | `printf("%g\n", 3.14159);`<br>`printf("%G\n", 3.14159);` | `3.14159`<br>`3.14159`           |
| `%c`        | 输出单个字符                        | `printf("%c\n", 'A');`                                   | `A`                              |
| `%s`        | 输出字符串                         | `printf("%s\n", "Hello, World!");`                       | `Hello, World!`                  |
| `%p`        | 输出指针的地址（十六进制形式）               | `printf("%p\n", &a);`（假设 `int a = 10;`）                  | `0x7fff5fbff6fc`（示例地址）           |
| `\n");`                                        | `%`                              |

长度修饰符

| 修饰符  | 说明                                       |
| ---- | ---------------------------------------- |
| `%ld`  | 用于 long int或 unsigned long int           |
| `%lld` | 用于 long long int或 unsigned long long int |
| `%Lf`  | 用于 long double                           |

示例：

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	float pi = 3141592653.589793;    
	int x = 8141244;    
	long long int lli= 1000;    
	
	printf("---%d---\n", x); // ---8141244---    
	printf("---%u---\n", x); // ---8141244---    
	printf("---%i---\n", x); // ---8141244---    
	printf("---%o---\n", x); // ---37034674---    
	printf("---%x---\n", x); // ---7c39bc---    
	printf("---%f---\n", pi); // ---3141592576.000000---    
	printf("---%e---\n", pi); // ---3.141593e+09---    
	printf("---%g---\n", pi); // ---3.14159e+09---    
	printf("---%G---\n", pi); // ---3.14159E+09---    
	printf("---%lld---\n", lli); // ---1000---    
	
	return 0;
}
```

# scanf 函数

作用：从终端读取数据，放入对应的变量中。

头文件：*# include <stdio.h>*

调用格式:

```c
scanf("读取格式字符串", 变量地址1, 变量地址2...);
```

常用读取格式

|占位符|说明|
|---|---|
|%d|读取十进制整数|
|%s|读取字符串|
|%f|读取小数|

取地址运算符 **&**

所用：返回变量的内存地址。

用法：

```c
& 变量
```

示例：

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	int x = 1; //    
	
	printf("---%p---\n", &x); // ---0x7ffc5c932b34---    
	printf("之前的x:%d\n", x);    
	scanf("%d", &x);    
	printf("读取之后的x:%d\n", x);    
	
	return 0;
}
