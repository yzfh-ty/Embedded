# 常量（字面值）- [菜鸟教程](https://www.runoob.com/cprogramming/c-constants.html)

字面值是写在程序中，有编译器来识别并转换为常数（不可变的数）的表示方式。

## 整数的字面值写法

```c
// char 类型整数的字面值'A'  
// 表示  65，类型为 signed char
// 整数的字面值写法:
// 十进制写法:100  
// 类型为 signed int100L 
// 类型为 signed long int
// 八进制写法0177
// 十六进制写法(0-9, A-F表示 10 ~15)
0xH~0xHHHHHHHH 0XH~0XHHHHHHHH 
0x1.    0x2.    0xa  或 0xA
0xFFFFFFFF
```

## 小数的字面值写法

```c
// 小数写法:3.14
// 指数写法:0.314E1 或 0.314e1  
// 表示 0.314 x 10 的 1 次方
```

## 复合字面值 （Compound literal）

作用：用于给结构体变量批量赋值。

语法

```c
(结构体类型) {成员列表}
```

示例

```c
#include <stdio.h>  
  
struct student {  
   char name[50];  // 姓名  
   int age;   // 年龄  
   float height; // 身高  
};  
  
int main(int argc, char * argv[]) {  
 struct student zhang3 = {"zhangsan", 18, 1.80 };  
  
 // 通过结构体变量来访问成员  
 printf("name:%s, age:%d, height:%f\n", zhang3.name, zhang3.age, zhang3.height);  
 // 使用符合字面值一次性的给结构体的各个变量赋值  
 zhang3 = (struct student){"zhangsanfeng", 19, 1.81};  
  
 printf("name:%s, age:%d, height:%f\n", zhang3.name, zhang3.age, zhang3.height);  
  
 return 0;  
}
```


# 变量 - [菜鸟教程](https://www.runoob.com/cprogramming/c-variables.html)

什么是变量

变量是用来保存数据的一段内存，变量通常有自己的名字，用来访问这段内存。

变量的定义方式

```c
变量的类型 变量的名字1 [= 变量的初始值1],变量的名字2 [= 变量的初始值2];
```

> *[ ]* 表示其中的内容可以省略

示例:

```c
char ch = 65;   # 申请一个字节，让他的初始值为 'A'(值为65)
signed char ch2;   # 申请一个字节，初始值未设定。
int money = 200;
unsigned int m; 
```

#### C 语言的变量名的命名规则

- 第一个字母必须是 英文字母 A-Z 、 a-z 或下划线。
- 第二个字母起（如果有）则必须是 英文字母 A-Z 或、a-z 、下划线或数字 0-9 。

合法的变量名:

```c
laowei     wei_ming_ze         wei123      a1b2c3
_abc       a1         x      y
```

不合法的变量名:

```c
1a         $a       
```

C 语言的关键字(保留字)不能用作变量名

```c
for     int    short     long     float   doublewhile    if    else      
switch   do      case
```

## 局部变量

函数内部声明的变量，和函数的形式参数都是局部变量。

局部变量只有在函数运行期间被创建，函数运行结束，局部变量自动销毁。

## 全局变量

全局变量是声明在函数外部，模块内部的变量。

全局变量是数据段的变量，他会随着程序的运行而创建，程序退出才销毁。

说明:

- 全局变量通常声明在模块(.c文件）的最上面。
- 一个模块内只能有一个同名的全局变量。
- 任何一个函数都有可能改变全局变量的值，因此要慎重使用全局变量。
- 全局变量如果没有给出初始值，则初始值默认0值（具体要看编译器）。

命名空间

一个程序优先访问局部变量。如果局部变量不存在才访问全局变量。

示例

```c
#include <stdio.h>  
  
int money = 10000000; // 全局变量 money;  
int * p;  
const double pi = 3.14;  
void hello(void) {  
 money = 0;  
}  
int main(int argc, char * argv[]) {  
 // int money = 200;  
  
 printf("%d\n", money);  
 hello();  
 printf("%d\n", money);  
 return 0;  
}
```
