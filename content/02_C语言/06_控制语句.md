# 选择语句（也叫分支语句）

选择语句的种类：

- if (表达式) 语句
- if (表达式) 语句1 else 语句2
- switch (表达式) 语句

## if 语句

作用：根据条件表达式的值来选择性的执行语句。

语法格式：

```c
if (表达式) 语句1或if (表达式) 语句1 else 语句2
```

> if 和 else 是关键字。

示例：

写一个程序，输入一个正整数，打印出这个整数是**奇数**还是**偶数。**

奇数：不能被 2整除的数，如：1 3 5 7。

偶数：能被 2整除的数，如：2 4 6 8 0。

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	unsigned int number;    
	
	printf("请输入整数：");    
	scanf("%d", &number);        
	
	if (number % 2 == 1)         
		printf("%d 是奇数\n", number);    
	else        
		printf("%d 是偶数\n", number);    
		
	return 0;
}
```

练习1：

写一个程序，输入你的年龄，如果年龄大于 18 岁，显示 您可以申请入党。否则什么都不做。

参考答案：

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	int age;     
	
	printf("请输入年龄：");    
	scanf("%d", &age);        
	
	if (age >= 18)               
		printf("您可以申请入党\n");    
	
	return 0;
}
```

练习2：

改写上一个程序，输入你的年龄，如果年龄大于 18 岁，显示您可以申请入党。否则提示您还没长大，请好好学习

参考答案：

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	int age;    
	
	printf("请输入年龄：");    
	scanf("%d", &age);

		printf("您可以申请入党\n");    
	else        
		printf("您还没长大，请好好学习\n");

}
```

## 语句

语句是计算机执行的最小单位。

语句的两种写法：

1. 表达式后加分号，如:x = 100;
    
2. 使用 大括号 {}，内部可以写入0~多条语句成为一条语句。
    
    - 如: {x = 100; x ++; printf("%d\n", x);}

if 语句嵌套实现多分支结构

```c
if (表达式) 语句1
// 或
if (表达式) 语句1 else 语句2
// 扩展应用
if (表达式) 
{    
	语句1
} else if (表达式) 
{    
	语句2 
} else if (表达式) 
{    
	语句3
} else 
{    
	语句4
}
```


练习：

写一个程序，输入年龄：

如果年龄小于 8 岁，打印“儿童”；

如果年龄大于8岁小于18岁，打印“少年”，

如果年龄大于18岁小于40岁，打印“青年”，

如果年龄大于40岁小于60岁，打印“中年”，

如果年龄大于60岁，打印“中老年”。

参考答案

```c
#include <stdio.h>  
  
int main(int argc, char * argv[]) {  
    int age;  
  
    printf("请输入年龄：");  
    scanf("%d", &age);  
  
    // 如果年龄小于 8 岁，打印“儿童”；  
    if (age < 8) {  
        printf("儿童\n");  
    } else if (age < 18) {  
        // 如果年龄大于8岁小于18岁，打印“少年”，  
        printf("少年\n");  
    } else if (age < 40) {  
        // 如果年龄大于18岁小于40岁，打印“青年”，  
        printf("青年\n");  
    } else if (age < 60) {  
        // 如果年龄大于40岁小于60岁，打印“中年”，  
        printf("中年\n");  
    } else {  
        // 如果年龄大于60岁，打印“中老年”。  
        printf("中老年\n");  
    }  
    return 0;  
}
```

## switch 语句

作用：根据表达式具体的取值，执行对应的语句（语句块）。

语法：

```c
switch (表达式) 
{    
	case 常量值1: 语句块1;    
	case 常量值2: 语句块2;    
	case 常量值3: 语句块3;    
	...     
	default: 语句块other;
}
```

语法说明：

- switch 语句先计算 表达式的值，然后用此值自上而下比较 case 中的常数值，直至找到一个相等的值，然后执行匹配的语句块。
- 如果 此语句块内没有用 break 语句终止执行 switch,则会向下执行所有的语句块，直至结束。

**break 语句**：

作用：用于终止当前 switch、for、while、do-while语句的执行。

示例：

写一个程序，输入成绩的级别:A 级（90-100)，B级（80-89)，C级（70~79）， D级（60-69)，E 级（0-59)。输入级别，打印分数范围。

```c
#include <stdio.h>  
int main(int argc, char * argv[]) {  
   char ch;  
  
   printf("请输入一个字符:");  
   scanf("%c", &ch);  // A 或 a  
   switch (ch) {  
       case 'A':  
       case 'a':  
           printf("90~100\n");  
           break;  
       case 'B':  
       case 'b':  
           printf("80~89\n");  
           break;  
       case 'C':  
       case 'c':  
           printf("70~79\n");  
           break;  
       case 'D':  
       case 'd':  
           printf("60~69\n");  
           break;  
       case 'E':  
       case 'e':  
           printf("0~59\n");  
           break;  
       default: printf("您的输入有错误\n");  
   }  
}
```

# 循环语句 (Iteration statements)

C 语言中的循环语句有 3 种：

1. for 语句
2. while 语句
3. do-while语句

## for 语句

语法

```c
for (初始化表达式【1】; 条件表达式【2】; 后处理表达式【3】)    语句1【4】
```

作用：根据条件表达式重复执行语句1。

语法说明：

1. **初始化表达式**会在 for语句运行时，最先运行，且只运行一次
2. **条件表达式**然后运行，当表达式返回真值，则执行语句1，否则结束循环。
3. 当执行完语句1， 再执行 **后处理表达式**。然后跳转到条件表达式，执行第2步。

- 初始化表达式可以为空，后处理表达式可以为空，
- 条件表达式可以为空，为空时表示条件一直成立。

最简写法（条件一直成立的循环）：

```c
for (;;) {}
```

> **Ctrl + c** 可以终止正在执行的程序。

示例

打印 1~10 十个整数。

```c
#include <stdio.h>  
int main(int argc, char * argv[]) {  
    int number;  // 用于控制循环次数的变量  
  
    for (number = 1; number <= 10; number ++) {  
        printf("%d\n", number);  
    }  
    printf("number:%d\n", number); // ??? 
     
    return 0;  
}
```

练习1:

打印 1 ~ 101 之间所有的偶数。

练习2:

打印 1 ~ 100 之间所有的奇数的和。

## while 语句

作用：根据条件重复的执行语句或语句块。

语法

```c
while (表达式) 语句
```

```c
while (表达式)  {    ...}
```

练习：

写一个程序，打印 1 ~ 101 之间所有偶数，最后打印这些偶数的和。使用while语句实现。

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	int number;    
	int total_number = 0;    
	
	number = 2;    
	
	while (number < 101) 
	{        
		printf("%d\n", number);        
		total_number += number;        
		number += 2;    
	}    
	printf("和是:%d\n", total_number);    
	
	return 0;
}
```

## do-while 语句

作用：用于循环

特点：先执行语句，再判断是否循环。

语法

```
do {
   语句
} while ( 表达式 ) ;
```

示例

写一个程序：输入密码，如果密码不是 123456 则继续输入。否则提示登录成功，退出程序。

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	int pwd;    
	
	do {        
		printf("请输入密码：");        
		scanf("%d", &pwd);    
	} while( pwd != 123456);    
	
	printf("登陆成功!");    
	
	return 0;
}
```

# 跳转语句

四种：

- break 语句
- continue 语句
- return 语句
- jump 语句

## break 语句

作用： 终止包含他的当前的 switch 、for 、while 、do-while  语句。

语法

```c
break;
```

说明：

- 当上述语句嵌套时，break 只能跳出离他最近的上述语句。

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
	{    
	int pwd;    
	
	do {        
		printf("请输入密码：");        
		scanf("%d", &pwd);        
		// 如果用户输入的是888888， 则提示大佬请进,结束循环        
		if (pwd == 888888) {            
			printf("大佬请进\n");            
			break;        
		}    
	} while( pwd != 123456);    
	
	printf("登陆成功!\n");    
	
	return 0;
}
```

## continue 语句

作用：

用于循环语句( for 、while 、do-while )中，放弃本次循环 continue 之后的语句的执行，重新结束开始一次新的循环。

语法

```c
continue;
```

说明：

- for 语句:自动执行后处理表达式（如 i++ ），然后检查条件表达式。
- while 语句：直接回到条件判断，需手动更新循环变量，否则可能死循环。
- do-while 语句：直接回到条件判断（位于循环尾部），需手动更新变量。

示例

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	int i = 0;    
	for (i = 0; i < 3; i++) {        
		printf("1\n");        
		printf("2\n");        
		continue;        
		printf("3\n");    
	}    
	return 0;
}
```

## goto 语句

作用：无条件的跳转到 标号指定的位置。

语法:

```c
goto 标号;
```

标号定义的语法:

```c
标号:
```

> 标号一定是 **标识符。** 并放在函数的内部。
> 
> **标识符**是变量名的命名规则。

示例:

```c
#include <stdio.h>

int main(int argc, char * argv[]) {

lable1:

    printf("hello world!\n");
    goto lable1;

    return 0;
}
```

## return 语句

作用：结束当前函数的执行，返回到调用此函数的地方。

语法:

```c
return [表达式];
```

> 如何函数的返回类型为 void 类型，则不需要表达式。

C 语言函数的约定:

- 函数返回 0 表示成功
- 函数返回非 0 值表示失败。

main 函数的返回值:

- 返回值必须在 0~255区间内（一个字节）。
