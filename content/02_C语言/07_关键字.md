## const

编译器级别限定符，可以通过指针修改

作用：const 关键字用来将变量声明为不可变变量，即在使用过程中不修改变量的值。

**声明方式**

```c
const 变量类型 变量名 = 初始值;
```

**说明:**

- const 是类型限定符，限定他修饰的变量不可改变。
- const 声明的变量必须给定初始值。

**示例**

```c
const double pi = 3.1415926  
pi = 100; // 报错  
int x = 100;  
const int * p;  // p 指向的内容为 const int 不可以修改。  
p = &x;  
*p = 200; // 报错
```

**相关用法**

```c
char * p; // 指向 char 类型数据的指针。  
const char *p; // 指向 const char 类型数据的指针。  
const char * const p; // 指向 const char 类型数据的常变量的指针。  
char ** p;  // 指向 char * 类型数据的指针。  
char *(*p)[5];  // 指向 含有5个 char* 类型的一维数组的 指针。  
int *p[5];  // 含有5个 int * 类型的指针的一维数组，sizeof(p)为40。  
int arr[5];  //含有5个 int 类型数据的一维数组，sizeof(arr)为20。
```

| 用法        | 说明                        | 示例                                                 |
| --------- | ------------------------- | -------------------------------------------------- |
| 常量定义      | 定义一个不可修改的变量，其值在定义后不能被改变。  | `const int MAX = 100;`                             |
| 指针修饰      | 修饰指针时，可以指定指针指向的内容是否可变。    | `const int* ptr;` // 指向常量的指针，不能通过指针修改内容            |
| 指针修饰      | 修饰指针时，可以指定指针本身是否可变。       | `int* const ptr = &var;` // 指针本身是常量，指向的地址不能改变      |
| 指针修饰      | 同时修饰指针和内容。                | `const int* const ptr = &var;` // 指针和指向的内容都是常量     |
| 函数参数      | 修饰函数参数，表示该参数在函数内部不会被修改。   | `void print(const char* str);` // 参数`str`在函数内部不可修改 |
| 函数返回值     | 修饰函数返回值，表示返回值不能被修改。       | `const int* getConstPointer();` // 返回的指针指向的内容不能被修改 |
| 结构体/联合体成员 | 修饰结构体或联合体的成员，使其在初始化后不可修改。 | `struct { const int value; } myStruct;`            |

> const修饰的变量或对象在定义后不能被修改。
> 在指针中，const的位置决定了修饰的是指针本身还是指针指向的内容。
> 在函数中，const用于提高代码的可读性和安全性，防止意外修改数据。

## static

**两种用法**:

- 修饰全局变量，限制全局变量名或函数名只在当前模块（.c文件）内使用，不导出到其他模块。
- 修饰局部变量，使其变成静态局部变量。
    - 静态局部变量是声明在函数内部的全局变量，一次定义，始终能够使用（函数退出也不销毁）。
    - 静态局部变量只能在函数内部使用。

**修饰全局变量示例**

m1.c

```c
#include <stdio.h>  
int number = 100;  
void print_m1(void) {  
    printf("print_m1: %d\n", number);  
}
```

m2.c

```c
#include <stdio.h>  
int number = 200;  
void print_m2(void) {  
    printf("print_m2: %d\n", number);  
}
```

file: main.c

```c
extern void print_m1(void);  
extern void print_m2(void);  
  
int main(int argc, char * argv[]) {  
    print_m1();  
    print_m2();  
}
```

链接阶段报错，将其中的一个改为 `static int number = xxx`; 即可解决变量名冲突问题。

**例子（只初始化一次）**

```c
#include <stdio.h>

int counter(int i)
{
    static int count = 0;
    count = count + i;
    return (count);
}

int main()
{
    int i, j;
    for (i = 0; i <= 5; i++)
        j = counter(i);
    
    // 程序执行到最后，j的值是15
    return 0;
}
```

## extern

**作用：**

用于跨模块的全局变量和函数的声明，声明变量或函数是在其他的模块中定义，在此模块中使用。

**语法**

```c
extern 变量类型 变量名 [, 变量名2]
```

**示例：**

文件：main1.c

```c
#include <stdio.h>  
#include "mymath.h"  
  
int main(int argc, char * argv[]) {  
    printf("%d\n", myadd(100, 200)); // 300  
    printf("%d\n", mymul(300, 400)); // 120000  
    printf("%d\n", total_numbers); // 1000  
  
    return 0;  
}
```

文件：mymath.c

```c
int total_numbers = 0; // 全局变量  
int myadd(int x, int y) {  
    int result = x + y;  
    total_numbers += result;  
    return result;  
}  
int mymul(int x, int y) {  
    int result = x * y;  
    total_numbers += x + y;  
    return result;  
}
```

文件：mymath.h

```c
// 声明 total_numbers 是 int 类型;  
extern int total_numbers;  
extern int myadd(int x, int y);  
extern int mymul(int x, int y);
```

## volatile

**作用：**指示编译器，volatile修改变量不允许优化掉。

**示例**

```c
#include <stdio.h>  
  
int main(int argc, char * argv[]) {  
    const int x = 100;  
    volatile int y = x; // 禁止编译器优化y这个变量。  
    int z = y;  
    printf("z:%d\n", z);  
    return 0;  
}
```

## typedef

用于将复杂的类型定义别名，方便使用，方便跨平台移植代码。

**语法:**

```
typedef 旧的类型  新的类型名;
```

```c
#include <stdio.h>  
  
typedef unsigned char uint8;  
typedef unsigned short int uint16;  
typedef unsigned int uint32;  
typedef unsigned long int uint64;  
typedef const char * pchar_t;  
  
int main(int argc, char * argv[]) {  
 uint64 x = 0;  
 const char * phello = "hello";  
 pchar_t pworld = "world";  
  
 printf("x:%ld\n", x);  
 printf("phello:%s\n", phello);  
 printf("pworld:%s\n", pworld);  
  
 return 0;  
}

/****************************定义方式****************************/

	int score;
}；
// student 可以省略 直接定义
typedef stuuct {  
	char name[50];
	int age;
	int score;
} stu；

```

```c
// 指向函数的指针的类型别名  
#include <stdio.h>  
  
int myadd(int x, int y) {  
 printf("myadd(%d, %d) is called\n", x, y);  
 return x + y;  
}  
  
int mymul(int x, int y) {  
 printf("mymul(%d, %d) is called\n", x, y);  
 return x * y;  
}  
// 定义int(int,int) 类型函数的别名 PFUN;  
typedef int(*PFUN)(int,int);   
int main(int argc, char * argv[]) {  
 // 定义函数指针  
 // int (*p_fun)(int,int) = mymul;  
 PFUN p_fun = mymul;  // 等同于上述函数指针变量的定义  
  
 // 使用函数指针来调用指向的函数  
 p_fun(100, 200);  
 p_fun = myadd;  
 p_fun(300, 400);  
  
 return 0;  
}
```
