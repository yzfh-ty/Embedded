## const

编译器级别限定符，可以通过指针修改

作用：const 关键字用来将变量声明为不可变变量，即在使用过程中不修改变量的值。

### 声明方式

```c
const 变量类型 变量名 = 初始值;
```

说明:

- const 是类型限定符，限定他修饰的变量不可改变。
- const 声明的变量必须给定初始值。

示例

```c
const double pi = 3.1415926  
pi = 100; // 报错  
int x = 100;  
const int * p;  // p 指向的内容为 const int 不可以修改。  
p = &x;  
*p = 200; // 报错
```

# static

静态变量，只初始化一次

例子
```c
#include <stdio.h>

int counter(int i)
{
    static int count = 0;
    count = count + i;
    return (count);
}

int main()
{
    int i, j;
    for (i = 0; i <= 5; i++)
        j = counter(i);
    
    // 程序执行到最后，j的值是15
    return 0;
}
```
