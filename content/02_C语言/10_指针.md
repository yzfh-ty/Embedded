# 指针

## 什么是指针？

指针是用来保存另外一个变量地址的变量。

指针变量的声明方法:  [[02_C语言/07_关键字#const\|const与指针]]

```c
指向的变量的类型 * 指针变量名称1 [= 初始值1];
```

示例

```c
int i = 100;  // 声明整型变量 i,初始值为100
int j = 200;
int * p ;  // p 的类型是 int *p = &i;  // &取地址(64bit)
```

将 指针类型的变量指向某个变量

```c
指针变量名 = 变量地址：
```

指针解引用 `*`

```c
* 指针变量名 // 访问指针指向的地址。
```

说明:

- 使用指针解引用（放在表达式中），则取指向变量的值。
- 对指针解引用赋值。则修改指向的变量的值。

练习:

```
写一个程序，声明 3个 char 类型的变量 a、b、c
声明 3个 int 类型的变量 x、y、z。
a 的初始值是 65
x 的初始值是 999
1. 声明char 类型指针变量 pc1 指向 a，pc2 指向b。不使用 abc 三个变量，将 b 的值改成和 a 相同。

打印 a b c 的值。
2. 声明 int 类型指针变量 pi,先将其指向 x,使用 pi 修改x的值为原来的值加上一。
3. 将 pi 指向 y,使用 pi 修改y的值为666.
4. 使用 pi 指向 z ，使用 pi 直接打印 z 的值。
5. 打印 pi 和 pc1、pc2占用的内存长度:sizeof()
```

## 空指针

空指针提供了一种安全的方式来表示指针当前没有指向任何有效的内存地址，空指针是值为0的指针，通常写成 NULL。

空指针（Null Pointer）是一种特殊的指针，它不指向任何有效的内存地址。在C语言中，我们通常使用 NULL 宏来表示空指针，它的值通常被定义为整数 0。空指针的概念很简单：它就是一个不指向任何地方的指针。

如:

```c
int * p = NULL;
```

空指针的使用非常安全，因为大多数现代操作系统都会在程序试图访问空指针时立即终止程序，从而防止可能的数据损坏或安全漏洞。这种行为使得空指针成为检测指针是否有效的有用工具

## 野指针

野指针则代表了一种潜在的危险，指向不确定位置的指针，需要我们在编程时格外小心

野指针（Dangling Pointer）则是一个完全不同的概念。野指针是指向无效内存或者已被释放的内存的指针。与空指针不同，野指针指向的是一个“随机”的内存位置，这个位置可能包含任何数据，甚至可能是另一个正在运行的程序的数据。使用野指针可能导致程序崩溃、数据损坏或安全漏洞。  
 

野指针通常在以下情况下产生：

- 使用未初始化的指针；
- 指针所指向的内存已经被释放（例如使用 free() 函数后）；
- 指针超出了变量的作用域。  
     

以下是野指针的示例：

```c
int *createArray() {
    int arr[5] = {1, 2, 3, 4, 5};
    return arr;  // 返回局部变量的地址，这将导致野指针
}

int main() {
    int *ptr = createArray();
    printf("%d\n", ptr[0]);  // 使用野指针，结果不可预测
    return 0;
}
```

```c
#include <stdio.h>  
int main(int argc, char * argv[]) 
{    
	unsigned char *puc; // puc 的之不确定，叫做野指针    
	*puc = 100;    
	return 0; 
}
```

为了避免野指针带来的问题，我们可以采取以下措施：
- 始终初始化指针，如果暂时没有有效的地址可以赋值，就将其初始化为 NULL。
- 在释放指针所指向的内存后，立即将指针设置为 NULL。
- 使用智能指针或其他内存管理技术来自动处理指针的生命周期。

## 悬空指针

**定义**

悬空指针是指指向已经被释放（或不再有效）的内存地址的指针。换句话说，指针仍然保存着一个地址值，但该地址对应的内存已经被释放，因此指针指向的内存区域不再属于程序合法的管理范围。

**产生原因**

动态内存释放后未置空指针：当使用free()（C语言）或delete（C++）释放动态分配的内存后，如果指针没有被置为空（NULL或nullptr），它仍然指向原来的地址，但该地址的内存已经不再属于程序。
示例：

```c
int* p = (int*)malloc(sizeof(int));
*p = 10;
free(p); // 释放内存
// 此时p仍然是一个悬空指针，它指向的内存已被释放
```

局部变量的地址被引用后超出作用域：如果在函数中将局部变量的地址赋给指针，当函数返回后，局部变量的存储空间被释放，指针就变成了悬空指针。
示例：

```c
int* getPointer()
{
    int a = 10;
    return &a; // 返回局部变量的地址
}
int* p = getPointer();
// 此时p是一个悬空指针，因为局部变量a的存储空间在函数返回后被释放
```

**危害**

悬空指针可能导致程序访问非法内存，从而引发未定义行为，如程序崩溃、数据损坏或产生错误的计算结果。例如，如果尝试通过悬空指针修改或访问内存，可能会覆盖其他重要数据，或者触发操作系统对非法内存访问的保护机制。

**解决方法**

在释放内存后，立即将指针置为空（NULL或nullptr），这样可以避免误用悬空指针。
示例：

```c
int* p = (int*)malloc(sizeof(int));
free(p);
p = NULL; // 将指针置为空
```

避免返回局部变量的地址，可以使用动态分配的内存或静态变量来解决。

## 悬空指针和野指针的区别

1. **状态不同**
    - 悬空指针曾经指向过有效的内存，但由于内存被释放等原因，现在指向的内存不再有效。
    - 野指针从未正确初始化或被错误地修改，指向一个完全未知的内存地址。
2. **产生原因不同**
    - 悬空指针通常是因为动态内存释放后未置空指针，或者局部变量地址超出作用域。
    - 野指针通常是因为指针未初始化、指针运算错误或指针赋值错误。
3. **调试难度不同**
    - 悬空指针的调试相对容易一些，因为它的地址是已知的（曾经有效），可以通过检查内存释放操作和指针的使用来定位问题。
    - 野指针的调试难度较大，因为它指向的地址是随机的，行为难以预测。

## void类型的指针

void 指针是一种特殊的指针，表示为“无类型指针”，由于 void 指针没有特定的类型，因此它可以指向任何类型的数据。也就是说，任何类型的指针都可以直接赋值给 void 指针，而无需进行其他相关的强制类型转换

```c
void *p1;
int *p2;
…
p1 = p2;
```

虽然如此，但这并不意味着可以无需任何强制类型转换就将 void 指针直接赋给其他类型的指针，因为“空类型”可以包容“有类型”，而“有类型”则不能包容“空类型”。

```c
void *p1;
int *p2;
…
p2 = (int*)p1;
```

**避免对void指针进行算术操作**

由于标准不一样，有些编译器可能可以，有些不行会报错

ANSI C 标准规定，进行算法操作的指针必须确定知道其指向数据类型大小，也就是说必须知道内存目的地址的确切值；而 GNU 则不这么认为，它指定“void*”的算法操作与“char*”一致

GNU 和 ANSI 还存在着一些区别，相比之下，GNU 较 ANSI 更“开放”，提供了对更多语法的支持。但是在真实的设计环境中，还是应该尽可能符合 ANSI 标准，尽量避免对 void 指针进行算术操作。

## 二级指针

二级指针：指向指针的指针（保存的是指针的地址）。

指针变量也是一种变量，也会占用存储空间，也可以使用`&`获取它的地址。C语言不限制指针的级数，每增加一级指针，在定义指针变量时就得增加一个星号`*`。p1 是一级指针，指向普通类型的数据，定义时有一个`*`；p2 是二级指针，指向一级指针 p1，定义时有两个`*`

例子

```c
#include <stdio.h>

int main(){
    int a =100;
    int *p1 = &a;
    int **p2 = &p1;
    int ***p3 = &p2;

    [printf](https://c.biancheng.net/view/ublxqif.html)("%d, %d, %d, %d\n", a, *p1, **p2, ***p3);
    printf("&p2 = %#X, p3 = %#X\n", &p2, p3);
    printf("&p1 = %#X, p2 = %#X, *p3 = %#X\n", &p1, p2, *p3);
    printf(" &a = %#X, p1 = %#X, *p2 = %#X, **p3 = %#X\n", &a, p1, *p2, **p3);
    return 0;
}
```

以三级指针 p3 为例来分析上面的代码。`***p3`等价于`*(*(*p3))`。`*p3` 得到的是 `p2` 的值，也即 `p1` 的地址；`*(*p3)` 得到的是 `p1` 的值，也即 `a` 的地址；经过三次“取值”操作后，`*(*(*p3))` 得到的才是 `a` 的值。

## 指针的运算

指针是一个变量，指针 加 1 内部的值向后移动 指向的类型的字节数。

```
short int i;
short int *pi = &i;
printf("%p\n", pi); 0x112244
pi++;
printf("%p\n", pi); 0x112244
```

指针的下标运算

语法

```c
指针p [整数表达式n]
等同于 
*(p+n)
```

他是指针指向的位置的第n个变量的引用。

示例

```c
#include <stdio.h>  
  
int main(int argc, char * argv[]) {  
    int scores[10] = {10, 20, 30, 40};   
    int *p = scores;  
  
    printf("scores[0]:%d\n", scores[0]);  
    printf("p[0]:%d\n", p[0]);  
     
    printf("scores[2]:%d\n", scores[2]);  
    printf("p[2]:%d\n", p[2]);  
    printf("*(p+2):%d\n", *(p+2));  
    printf("*(scores+2):%d\n", *(scores+2));  
    return 0;  
}
```

## 函数指针

函数是代码段的一段CPU指令，函数名是一个常量地址，是该函数的起始地址。使用指针可以指向这段地址，并可以调用该函数。

作用：

使用指针调用函数。

指向函数的指针称为函数指针：

定义语法

```c
返回类型 (*指针变量名)(形参类型1, 形参类型2, 形参类型3);
```

示例

```c
#include <stdio.h>  
  
int myadd(int x, int y) {  
 printf("myadd(%d, %d) is called\n", x, y);  
 return x + y;  
}  
  
int mymul(int x, int y) {  
 printf("mymul(%d, %d) is called\n", x, y);  
 return x * y;  
}  
  
int main(int argc, char * argv[]) {  
 // 定义函数指针  
 int (*p_fun)(int,int) = mymul;  
  
 // 使用函数指针来调用指向的函数  
 p_fun(100, 200);  
 p_fun = myadd;  
 p_fun(300, 400);  
  
 return 0;  
}
```

## 复杂指针的定义方法

使用 `(*)` 替换变量名的办法：

```c
// 指向一维数组的指针  
int arr[10];  
int (*arr)[10];  
// 指向二维数组的指针  
int * arr2d[3][4];  
int * (*parr2d)[3][4];  
  
// 指向函数的指针  
int myadd(int x, int y);  
int (*pmyadd)(int, int);  
int x;  
int *px;  
  
int a[3][4];  
a返回的类型为 int (*p) [4];
```

**复杂指针的类型别名 typedef**

```c
// 指向函数的指针的类型别名  
#include <stdio.h>  
  
int myadd(int x, int y) {  
 printf("myadd(%d, %d) is called\n", x, y);  
 return x + y;  
}  
  
int mymul(int x, int y) {  
 printf("mymul(%d, %d) is called\n", x, y);  
 return x * y;  
}  
// 定义int(int,int) 类型函数的别名 PFUN;  
typedef int(*PFUN)(int,int);   
int main(int argc, char * argv[]) {  
 // 定义函数指针  
 // int (*p_fun)(int,int) = mymul;  
 PFUN p_fun = mymul;  // 等同于上述函数指针变量的定义  
  
 // 使用函数指针来调用指向的函数  
 p_fun(100, 200);  
 p_fun = myadd;  
 p_fun(300, 400);  
  
 return 0;  
}
```
