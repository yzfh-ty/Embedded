# 函数

什么是函数

函数是实现了一些功能的代码块。函数可以一次定义，多次使用。

函数的构成分为两部分：

1. 声明
2. 定义

## 定义函数的语法

```c
返回值的类型 函数名( 形式参数变量列表 ) {
    语句
}
//
返回值的类型 函数名(类型1 变量1, 类型2 变量2, ...) {
    语句
}
```

说明：

- 返回值的类型表示函数的返回值（函数的输出）的类型，如果函数没有返回值，可以定义为 `void` 类型。
- 函数名必须是**标识符。**
- 形式参数变量列表是一系列变量的声明列表，表示函数的输入。

示例

写一个函数 myadd，函数有两个整数输入 ，返回两个数的和。

```c
#include <stdio.h>  
  
int myadd(int x, int y) {   
    printf("myadd 已经调用\n");  
    return x + y;  
}  
  
int main(int argc, char * argv[]) {  
    int a;  
    int b;  
  
    printf("请输入第一个数");  
    scanf("%d", &a);  
    printf("请输入第二个数");  
    scanf("%d", &b);  
    int result;  
    result = myadd(a, b); // 调用 myadd函数  
    printf("result:%d\n", result);  
  
    result = myadd(1, 5);  
    printf("result:%d\n", result);  
    return 0;  
}
```

**没有参数和返回值的函数的定义方法：**

```c
void hello(void) {  
    printf("hello world!\n");  
}  
int main(int argc, char * argv[]) {  
    hello();  
    return 0;  
}
```

**返回指针的函数的定义方法**

```c
int * max_number_addr(int * pa, int * pb) {  
    if (*pa > *pb)   
        return pa;  
    return pb;  
}  
int main(int argc, char * argv[]) {  
    int x = 100;  
    int y = 200;  
    int * max_p = max_number_addr(&x, &y);  
    printf("%d\n", *max_p);  
}
```


## 函数的声明

函数的声明是告诉编译器遇到的标识符的类型是什么。函数要先声明后使用。

如果函数定义放在主函数上面，则不用单独添加函数声明

函数声明的语法

```
返回值的类型 函数名(类型1 [变量名1], 类型2 [变量名2], ...);
```

> `[]` 表示变量可以名可以省略。

示例

```
// my_max 函数的声明
float my_max(float, float);
```

## 函数的调用

函数调用的语法

```c
函数名(实际调用参数列表)
//
函数名(表达式1, 表达式2, ...)
```

示例:

```c
#include <stdio.h>  
  
int myadd(int x, int y) {   
    printf("myadd 已经调用\n");  
    return x + y;  
}  
  
int main(int argc, char * argv[]) {  
    int a;  
    int b;  
  
    printf("请输入第一个数");  
    scanf("%d", &a);  
    printf("请输入第二个数");  
    scanf("%d", &b);  
    int result;  
    result = myadd(a, b); // 调用 myadd函数  
    printf("result:%d\n", result);  
  
    result = myadd(1, 5);  
    printf("result:%d\n", result);  
    return 0;  
}
```

## 传值和传址

在函数调用的过程中，函数的实际参数的值会传递给形势参数。这种传递方式被称为**传值**。

在函数内部，如果要修改实际参数的值，需要将实际参数的地址传递过去，称之为**传址。**

示例

```c
#include <stdio.h>  
  
void my_swap(int *pa, int *pb) {  
    int temp;   
    temp = *pb;  
    *pb = *pa;  
    *pa = temp;  
}  
  
int main(int argc, char * argv[]) {  
    int a = 100;  
    int b = 200;  
    // 如何能交换 a 和 b 的值。  
    my_swap(&a, &b);  
      
    printf("a:%d,b:%d\n", a, b);  
  
  
    return 0;  
}
```

数组传参

```c
void fun1(int a[3][5]) {}  
void fun2(int a[][5]) {}  
void fun2(int(*a)[5]) {}  
int main() {  
    int arr[3][5];   
}
```

示例
```c
#include <stdio.h>

void scan(int arr[][5], int line, int col)
{
    for (int i = 0; i < line; i++)
    {
        for (int j = 0; j < col; j++)
        {
            arr[i][j] = j + 1 + i;
        }
    }

}

void print (int arr[][5],int line, int col)
{
    for (int i = 0; i < line; i++)
    {
        for (int j = 0; j < col; j++)
        {
            printf("%d", arr[i][j]);
        }
        printf("\n");
    }

}

int main(int argc, char *argv[])
{
    int arr[3][5];

    scan(arr, 3, 5);
    print(arr, 3, 5);

    return 0;
}

```
