## getpid() 

作用：获取当前进程的进程标识符（Process ID）。

头文件：`#include <unistd.h>`（在 Unix-like 系统中）

调用格式：

```c
pid_t pid = getpid();
```

返回值：返回一个 `pid_t` 类型的整数，表示当前进程的 PID。

用途：在多进程编程中，用于标识和管理进程。

示例代码：

```c
#include <stdio.h>
#include <unistd.h>

int main() {
    pid_t pid = getpid();
    printf("Current Process ID: %d\n", pid);
    return 0;
}
```

示例输出：

`Current Process ID: 12345`

（输出的 PID 将根据实际运行环境而变化）
## rand()

作用：生成一个伪随机数。

头文件：`#include <stdlib.h>`

调用格式：

```c
int random_number = rand();
```

返回值：返回一个介于 `0` 到 `RAND_MAX` 之间的伪随机整数。

用途：用于需要随机数的场合，如游戏、模拟等。需要使用 `srand()` 来初始化随机数生成器。

示例代码：


```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main() {
    srand(time(NULL));
    int random_number = rand();
    printf("Random Number: %d\n", random_number);
    return 0;
}
```

示例输出：

`Random Number: 12345`

（输出的随机数将根据实际运行环境和种子值而变化）

## srand()

作用：设置随机数生成器的种子。

头文件：`#include <stdlib.h>`

调用格式：

```c
srand(unsigned int seed);
```

参数：一个无符号整数种子值。

返回值：无。

用途：通过传入不同的种子值，可以控制 `rand()` 生成的随机数序列。通常使用当前时间作为种子，以确保每次运行程序时生成不同的随机数序列。

示例代码：


```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main() {
    srand(time(NULL));
    int random_number = rand();
    printf("Random Number: %d\n", random_number);
    return 0;
}
```

示例输出：

`Random Number: 12345`

（输出的随机数将根据实际运行环境和种子值而变化）
## time()

作用：获取当前时间。

头文件：`#include <time.h>`

调用格式：

```c
time_t result = time(NULL);
```

参数：无。

返回值：返回自1970年1月1日（UTC）以来的秒数。

用途：用于获取当前时间，进行时间计算，或者作为随机数生成器的种子。

示例代码：

```c
#include <stdio.h>
#include <time.h>

int main() {
    time_t result = time(NULL);
    printf("Current Time: %ld\n", result);
    return 0;
}
```

示例输出：

`Current Time: 1643723400`

（输出的时间戳将根据实际运行环境而变化）

**通常使用上面那三个生成 ==伪== 随机数**

```c
#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    srand(time(0)); // 初始化随机数生成器，使用当前时间作为种子
    for (int i = 0; i < 5; ++i) {
        int random_number = rand(); // 生成随机数
        std::cout << "Random number: " << random_number << std::endl;
    }
    return 0;
}
```
