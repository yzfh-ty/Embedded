# 数组 array

什么是数组？

数组是一系列相同类型变量顺序存储的集合。数组中的所有成员的数据类型都是相同的。

问题：

如何存储 100 个学生的成绩？

## 一维数组的定义的语法

```c
数据类型 数组名[成员个数];数据类型 数组名[成员个数] = {初始值1, 初始值2, ...};
```

说明：

- 成员个数必须是大于等于零的整数。
    
- 初始值为依次为每个成员赋初始值，个数少于成员个数时，其他成员赋值零值
    
    - 整数是0；
    - 浮点数是0.0；

示例

```c
unsigned int scores[100];
double weight[100];
unsigned char age[100];
```

```c
int arr1[5];   // 直接指定数据元素的类型和个数；  
int arr2[5] = {1, 2} // 直接指定数据元素的类型和个数并赋予初始值，每个初始值的变量为零值；  
int arr3[] = {11, 22,33, 44}; // 编译器自动推  
导数据个数。  
// arr3 的类型是 int*  
int * p = arr3;  
*(p+1)  
p[1]

```

## 数组成员的访问和修改

### 索引 index

```c
数组名[整数表达式]    
```

此整数表达式通常叫索引。第一个变量的索引是0,第二个变量的索引是1,

写一个程序，输入任意个学生的成绩和年龄，当成绩为负数时结束输入。

打印已经输入的学生的成绩和年龄。

```c
#include <stdio.h>  
  
int main(int argc, char * argv[]) {  
    int count = 0; // 用来记录人数  
    unsigned int scores[100];  
    unsigned char age[100];  
  
    for (int i =0; i < 100; i++) {  
        int s, a;  
        printf("请输入成绩:");  
        scanf("%d", &s);  
        if (s < 0) // 停止输入  
            break;  
        printf("请输入年龄:");  
        scanf("%d", &a);  
        scores[i] = s;  // 保存成绩  
        age[i] = a;  
        count++;// 人数+1；  
    }  
    // 打印学生的编号，成绩和年龄  
    for (int i =0; i < count; i++) {  
        printf("%d: score:%d, age:%d\n", i+1,  
                scores[i], age[i]);  
    }  
  
    return 0;  
}
```

## 一维数组的名字的类型

- 一维数组的名字的值是数组第一个数据单元的首地址。
- 一维数组的名字的返回类型是数组中数据元素类型的指针。

```c
int scores[10]; //scores 的类型是 int*
```

## 一维数组形参的定义方法

- 直接用指针定义。`(int * pscore, ...)`
- 使用定长数组定义（少用）, `(int pscore[20], ....)`
- 使用不定长数组定义。`(int pscore[], ....)`

## 一维数组计算长度的方法

```c
int arr[100];  
// 计算数组长度（此方法只能在定义的函数中使用）；  
sizeof(arr) / sizeof(arr[0])
```
