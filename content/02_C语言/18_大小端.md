## 大小端

大小端（Endianness)是指计算存储多字节数据（如：short int、int、float、double等）时，各个字节在内存中的排列顺序。

### 小端模式

低位字节存储在低地址，高位字节存储在高地址。

小端表示

```
unsigned int x = 0x12345678;

+------+------+------+------+
| 0x78 | 0x56 | 0x34 | 0x12 |
+------+------+------+------+
低地址                    高地址
```

### 大端模式

高位字节存储在低地址，低位字节存储在高地址

大端表示

```
unsigned int x = 0x12345678;

+------+------+------+------+
| 0x12 | 0x34 | 0x56 | 0x78 |
+------+------+------+------+
低地址                    高地址
```

### 检测方法

使用 [[02_C语言/16_联合体\|联合体]] 进行检测，如上图所示，定义一个联合体

```c
union u_t {  
    unsigned char buf[4];  
    unsigned int x;  
}
```

将 整数 `0x87654321` 赋值给 `x`, 检查 `buf[0]` 是 `0x21` 就是小端,如果是 `0x87` 就是大端。
