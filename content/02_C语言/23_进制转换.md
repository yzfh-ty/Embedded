## 常见进制类型

- **二进制（Binary）**：基数为2，用0和1表示
- **八进制（Octal）**：基数为8，用0-7表示
- **十进制（Decimal）**：基数为10，用0-9表示
- **十六进制（Hexadecimal）**：基数为16，用0-9和A-F表示

## 进制转换方法

### 1. 其他进制转十进制（按权展开法）

**公式**：每一位数字 × 基数^位置指数

**示例**：
- 二进制 1101 转十进制：
  1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 8 + 4 + 0 + 1 = 13

- 十六进制 2A 转十进制：
  2×16¹ + 10×16⁰ = 32 + 10 = 42

### 2. 十进制转其他进制（除基数取余法）

**方法**：不断除以目标基数，取余数，直到商为0，余数倒序排列

**示例**：
- 十进制 13 转二进制：
  13÷2 = 6 余 1
  6÷2 = 3 余 0
  3÷2 = 1 余 1
  1÷2 = 0 余 1
  结果：1101

### 3. 二进制与八进制、十六进制互转

**二进制转八进制**：每3位二进制对应1位八进制
- 110101101 → 110 101 101 → 655

**二进制转十六进制**：每4位二进制对应1位十六进制
- 110101101 → 0001 1010 1101 → 1AD
