### 1. 数据结构基础

数据结构是计算机存储、组织数据的方式。它描述数据元素之间的逻辑关系以及对其进行的操作。常见的分类方式有两种：**物理结构（存储结构）** 和 **逻辑结构**。

### 2. 物理结构（存储结构）

物理结构是指数据在内存中的实际存储形式，通常包括以下两种：

#### （1）顺序存储结构（Sequential Storage）
- 数据元素在内存中占据连续的空间。
- 可通过下标直接访问元素（支持随机访问）。
- 典型结构如：数组、静态数组、动态数组。

##### 示例：
```c
int arr[100];             // 静态顺序存储
int *dynamic_arr = malloc(100 * sizeof(int));  // 动态顺序存储
```

#### （2）链式存储结构（Linked Storage）
- 数据元素不连续存放，通过指针相连。
- 插入/删除操作效率高（仅调整指针），但查找耗时。
- 包括：单链表、双向链表、循环链表等。

##### 示例：
```c
struct node {
    int data;
    struct node *next;
};
```

### 3. 逻辑结构

逻辑结构是从数据元素之间抽象出的逻辑关系角度对数据结构的分类。主要有以下四类：

#### （1）集合结构（Set Structure）
- 数据之间没有明确的关系。
- 每个元素都是独立的，可以看作“无序”或“无关”。

#### （2）线性结构（Linear Structure）
- 数据元素之间存在一对一的关系。
- 常见结构包括：栈、队列、线性表。
- 每个节点最多只有一个前驱和一个后继。

##### 示例结构：
```
A -> B -> C -> D ... （线性结构）
```

#### （3）树形结构（Tree Structure）
- 数据之间存在一对多的层次关系。
- 每个节点只有一个父节点，但可有多个子节点。
- 常用于表示层级数据，如目录结构、DOM树、语法树等。

##### 示例结构：
```
        A
       / \
      B   C
     /|   |\
    D E   F G
```

#### （4）图形结构（Graph Structure）
- 数据之间存在多对多的任意关系。
- 每个节点可能与其他任意节点相关联。
- 适用于社交网络、地图路径规划、依赖管理等场景。

##### 示例结构：
```
A — B — C
|     /
D —— E
```

### 4. 总结对比表：逻辑结构 vs 物理结构

| 类型       | 描述                               | 特点                                       |
|------------|------------------------------------|--------------------------------------------|
| 顺序存储   | 元素占用连续内存                   | 支持随机访问，插入删除效率低               |
| 链式存储   | 节点通过指针连接                   | 插入删除效率高，无法随机访问               |
| 集合结构   | 元素无关联                         | 无明显前驱后继                              |
| 线性结构   | 一对一关系                         | 如栈、队列、线性表                          |
| 树形结构   | 一对多关系                         | 结构分层，常用于层次模型                    |
| 图形结构   | 多对多关系                         | 表示任意连接，适合复杂关系建模              |
