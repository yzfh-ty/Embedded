# 📊 复杂度分析（Complexity Analysis）

## 📘 基础概念

复杂度分析是评估算法效率的重要工具，用于衡量算法执行所需的时间和空间资源随输入规模增长的变化趋势。它帮助我们选择最优算法，优化程序性能。

---

## 🎯 复杂度分析的主要目的

- 比较不同算法的优劣
- 预估算法在大规模数据下的表现
- 指导算法优化方向
- 评估系统资源消耗

---

## 📈 复杂度的分类

### 1️⃣ 时间复杂度（Time Complexity）
描述算法执行时间与输入规模的关系

### 2️⃣ 空间复杂度（Space Complexity）
描述算法所需存储空间与输入规模的关系

---

## 📚 渐进符号表示法

### 1️⃣ 大O记号：O(f(n))
表示算法的**上界**，描述最坏情况下的复杂度

```c
// O(1) - 常数时间
int getFirstElement(int arr[]) {
    return arr[0];  // 无论数组多大，都只执行一次
}

// O(n) - 线性时间
int findMax(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++) {  // 执行n次
        if (arr[i] > max) max = arr[i];
    }
    return max;
}

// O(n²) - 平方时间
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n-1; i++) {      // n次
        for (int j = 0; j < n-i-1; j++) { // n次
            if (arr[j] > arr[j+1]) {
                swap(&arr[j], &arr[j+1]);
            }
        }
    }
}
```

### 2️⃣ Ω记号（Omega）
表示算法的**下界**，描述最好情况

### 3️⃣ Θ记号（Theta）
表示算法的**紧确界**，同时是上界和下界

## 🔢 常见复杂度等级（从快到慢）

| 复杂度 | 名称 | 说明 | 典型算法 |
|--------|------|------|----------|
| O(1) | 常数 | 最优 | 数组随机访问 |
| O(log n) | 对数 | 非常好 | 二分查找 |
| O(n) | 线性 | 良好 | 遍历数组 |
| O(n log n) | 线性对数 | 较好 | 快速排序、归并排序 |
| O(n²) | 平方 | 可接受 | 冒泡排序、选择排序 |
| O(n³) | 立方 | 较差 | 三重循环 |
| O(2ⁿ) | 指数 | 很差 | 递归求斐波那契 |
| O(n!) | 阶乘 | 极差 | 旅行商问题暴力解法 |

## 🧮 时间复杂度分析方法

### 1️⃣ 基本规则

#### ▶ 加法规则
多个步骤顺序执行时，取最大复杂度：
```c
// O(n) + O(n²) = O(n²)
for (int i = 0; i < n; i++) {...}     // O(n)
for (int i = 0; i < n; i++) {         // O(n²)
    for (int j = 0; j < n; j++) {...}
}
```

#### ▶ 乘法规则
嵌套循环时，复杂度相乘：
```c
// O(n) × O(n) = O(n²)
for (int i = 0; i < n; i++) {         // O(n)
    for (int j = 0; j < n; j++) {...} // O(n)
}
```

### 2️⃣ 常见分析示例

#### ➤ 示例1：递归算法（斐波那契）
```c
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);  // O(2ⁿ)
}
```

#### ➤ 示例2：分治算法（二分查找）
```c
int binarySearch(int arr[], int left, int right, int target) {
    if (left > right) return -1;
    int mid = left + (right - left) / 2;
    if (arr[mid] == target) return mid;
    if (arr[mid] > target) 
        return binarySearch(arr, left, mid-1, target);  // T(n/2)
    else 
        return binarySearch(arr, mid+1, right, target); // T(n/2)
}
// 时间复杂度：T(n) = T(n/2) + O(1) = O(log n)
```

#### ➤ 示例3：动态规划（斐波那契优化版）
```c
int fib(int n) {
    if (n <= 1) return n;
    int dp[n+1];
    dp[0] = 0; dp[1] = 1;
    for (int i = 2; i <= n; i++) {  // O(n)
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
// 时间复杂度：O(n)，空间复杂度：O(n)
```

## 💾 空间复杂度分析

### 1️⃣ 计算原则
只计算算法执行过程中额外使用的存储空间，不包括输入数据本身

### 2️⃣ 常见情况

#### ▶ O(1) - 常数空间
```c
int sum(int arr[], int n) {
    int result = 0;  // 只使用常数个变量
    for (int i = 0; i < n; i++) {
        result += arr[i];
    }
    return result;
}
```

#### ▶ O(n) - 线性空间
```c
int* copyArray(int arr[], int n) {
    int* copy = malloc(n * sizeof(int));  // 额外分配n个空间
    for (int i = 0; i < n; i++) {
        copy[i] = arr[i];
    }
    return copy;
}
```

#### ▶ O(log n) - 对数空间（递归调用栈）
```c
int binarySearch(int arr[], int left, int right, int target) {
    // 递归深度为log n，栈空间为O(log n)
}
```

## 🎯 实战分析技巧

### 1️⃣ 分析步骤
1. 确定基本操作
2. 计算执行次数
3. 简化表达式（忽略低阶项和常数系数）
4. 确定复杂度等级

### 2️⃣ 常见陷阱避免

#### ❌ 错误示例：
```c
// 这里看起来是O(n²)，实际是O(n)
for (int i = 0; i < n; i++) {
    for (int j = i; j < n; j++) {  // 内循环次数递减：n + (n-1) + ... + 1
        // 操作
    }
}
// 总次数 = n(n+1)/2 = O(n²) ❌ 错了，其实是O(n²)
```
**更正：** 上述确实是O(n²)，但如果内循环与外循环无关，则可能是O(n)

#### 正确分析：
```c
// 真正的O(n)示例
int count = 0;
for (int i = 0; i < n; i++) {
    count++;  // 执行n次
}
// 时间复杂度：O(n)
```

## 优化复杂度的常用策略

### 空间换时间
使用额外存储空间来减少计算时间（如哈希表、预计算）

### 时间换空间
通过重复计算来节省存储空间（如递归代替动态规划）

### 分治思想
将大问题分解为小问题（如归并排序O(n log n)）

### 贪心策略
每步选择局部最优（如Dijkstra算法）

### 动态规划
存储中间结果避免重复计算

## 复杂度分析实战

### 示例1：查找数组中的重复元素

```c
// 方法1：暴力法 O(n²)
bool containsDuplicate(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (arr[i] == arr[j]) return true;
        }
    }
    return false;
}

// 方法2：哈希表法 O(n)
bool containsDuplicate(int arr[], int n) {
    int hash[100000] = {0};  // 假设值域
    for (int i = 0; i < n; i++) {
        if (hash[arr[i]]) return true;
        hash[arr[i]] = 1;
    }
    return false;
}
```
