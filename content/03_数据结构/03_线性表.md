### 线性表（Linear List）

线性表是最基础和常用的数据结构之一，其特点是数据元素之间存在**一对一的线性关系**。除了第一个和最后一个元素外，每个元素都有唯一的一个前驱和后继元素。

#### 逻辑特性
- 有且仅有一个“开始”元素（无前驱）
- 有且仅有一个“结束”元素（无后继）
- 除首尾元素外，其他元素都分别有唯一前驱和后继

线性表是**逻辑结构**的概念，具体实现可以采用多种物理结构（如顺序存储和链式存储）来完成。

## 顺序存储线性表（Sequential List）

### 实现方式：数组 / 动态数组

顺序表将数据存储在一个**连续的内存块**中，并通过索引直接定位元素。

#### 定义示例
以学生分数记录系统为例：
```c
#define MAX_SIZE 100

struct stu_score {
    int data[MAX_SIZE];  // 存储成绩数据
    int count;           // 当前有效元素个数
};
```
- `data[]`：固定大小的静态数组（或动态分配）
- `count`：当前元素数量

### 时间复杂度分析（基于静态数组实现）
| 操作                  | 时间复杂度 |
|----------------------|------------|
| 获取长度 / 判空      | O(1)       |
| 按位置访问（随机读取）| O(1)       |
| 插入元素到末尾       | O(1)       |
| 插入中间位置         | O(n)       |
| 删除中间位置         | O(n)       |

### 基础操作实现

#### 初始化表
```c
int init_data(struct stu_score *stu) {
    if (stu == NULL) return 0;
    stu->count = 0;
    return 1;
}
```

#### 插入元素到末尾（追加）
```c
int append_data(struct stu_score *stu, int score) {
    if (stu == NULL || stu->count >= MAX_SIZE) return 0;
    stu->data[stu->count++] = score;
    return 1;
}
```

#### 在指定位置插入元素
```c
int insert_data(struct stu_score *stu, int pos, int score) {
    if (stu == NULL || pos < 0 || pos > stu->count || stu->count >= MAX_SIZE)
        return 0;

    // 将插入位置后的元素向后移动
    for (int i = stu->count - 1; i >= pos; i--)
        stu->data[i + 1] = stu->data[i];

    stu->data[pos] = score;
    stu->count++;
    return 1;
}
```

#### 删除指定位置元素
```c
int remove_data(struct stu_score *stu, int pos) {
    if (stu == NULL || pos < 0 || pos >= stu->count) return 0;

    // 将被删除位置及其后面的元素前移
    for (int i = pos; i < stu->count - 1; i++)
        stu->data[i] = stu->data[i + 1];

    stu->count--;
    return 1;
}
```

#### 修改指定位置元素
```c
int modify_data(struct stu_score *stu, int pos, int score) {
    if (stu == NULL || pos < 0 || pos >= stu->count) return 0;
    stu->data[pos] = score;
    return 1;
}
```

#### 打印所有数据
```c
void list_all_data(const struct stu_score *stu) {
    if (stu == NULL) return;
    printf("学生个数：%d\n", stu->count);
    for (int i = 0; i < stu->count; i++)
        printf("%d ", stu->data[i]);
    printf("\n");
}
```

#### 销毁数据结构
```c
int destroy_data(struct stu_score *stu) {
    // 如果是动态分配则需要 free()
    return 1;
}
```

### 优势与局限性

#### 优点
- 支持**随机访问**，时间复杂度为 O(1)
- 内存紧凑，缓存友好
- 结构简单，易于实现

#### 缺点
- 插入/删除操作成本高（最坏情况为 O(n)）
- 需要预分配内存空间（静态数组）、扩展代价大（动态数组）
- 对于大数据量，可能造成内存浪费
