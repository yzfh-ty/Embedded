### 动态数组（Dynamic Array）

动态数组是顺序存储结构的一种改进形式，其核心特点是**容量可以根据需要动态扩展**，解决了静态数组容量固定的问题。

#### 核心思想
- 初始分配较小的内存空间
- 当元素数量达到上限时，重新分配更大的内存空间（通常是原来的2倍）
- 将旧数据复制到新空间，并释放旧空间

#### 数据结构定义
```c
#include <stdio.h>
#include <stdlib.h>

struct dynamic_array {
    int *data;        // 指向动态分配的内存
    int count;        // 当前元素个数
    int capacity;     // 当前分配的容量
};
```

#### 初始化动态数组
```c
int init_dynamic_array(struct dynamic_array *arr, int initial_capacity) {
    if (arr == NULL || initial_capacity <= 0) return 0;
  
    arr->data = (int*)malloc(sizeof(int) * initial_capacity);
    if (arr->data == NULL) return 0;
  
    arr->count = 0;
    arr->capacity = initial_capacity;
    return 1;
}
```

#### 扩容机制
当数组满时，通常采用**倍增策略**来扩容：
```c
int resize_dynamic_array(struct dynamic_array *arr) {
    if (arr == NULL) return 0;
  
    int new_capacity = arr->capacity * 2;
    int *new_data = (int*)realloc(arr->data, sizeof(int) * new_capacity);
  
    if (new_data == NULL) return 0;
  
    arr->data = new_data;
    arr->capacity = new_capacity;
    return 1;
}
```

#### 添加元素（尾部插入）
```c
int append_dynamic_array(struct dynamic_array *arr, int value) {
    if (arr == NULL) return 0;
  
    // 如果空间不足，先扩容
    if (arr->count >= arr->capacity) {
        if (!resize_dynamic_array(arr)) return 0;
    }
  
    arr->data[arr->count++] = value;
    return 1;
}
```

#### 指定位置插入元素
```c
int insert_dynamic_array(struct dynamic_array *arr, int pos, int value) {
    if (arr == NULL || pos < 0 || pos > arr->count) return 0;
  
    // 如果空间不足，先扩容
    if (arr->count >= arr->capacity) {
        if (!resize_dynamic_array(arr)) return 0;
    }
  
    // 元素后移
    for (int i = arr->count; i > pos; i--) {
        arr->data[i] = arr->data[i-1];
    }
  
    arr->data[pos] = value;
    arr->count++;
    return 1;
}
```

#### 删除指定位置元素
```c
int remove_dynamic_array(struct dynamic_array *arr, int pos) {
    if (arr == NULL || pos < 0 || pos >= arr->count) return 0;
  
    // 元素前移
    for (int i = pos; i < arr->count - 1; i++) {
        arr->data[i] = arr->data[i+1];
    }
  
    arr->count--;
    return 1;
}
```

#### 访问指定位置元素
```c
int get_dynamic_array(const struct dynamic_array *arr, int pos, int *value) {
    if (arr == NULL || pos < 0 || pos >= arr->count || value == NULL) return 0;
  
    *value = arr->data[pos];
    return 1;
}
```

#### 修改指定位置元素
```c
int set_dynamic_array(struct dynamic_array *arr, int pos, int value) {
    if (arr == NULL || pos < 0 || pos >= arr->count) return 0;
  
    arr->data[pos] = value;
    return 1;
}
```

#### 打印所有元素
```c
void print_dynamic_array(const struct dynamic_array *arr) {
    if (arr == NULL) return;
  
    printf("数组大小：%d，容量：%d\n", arr->count, arr->capacity);
    for (int i = 0; i < arr->count; i++) {
        printf("%d ", arr->data[i]);
    }
    printf("\n");
}
```

#### 销毁动态数组
```c
void destroy_dynamic_array(struct dynamic_array *arr) {
    if (arr == NULL) return;
  
    if (arr->data != NULL) {
        free(arr->data);
        arr->data = NULL;
    }
  
    arr->count = 0;
    arr->capacity = 0;
}
```

#### 时间复杂度分析

| 操作 | 平均时间复杂度 | 最坏时间复杂度 | 说明 |
|------|----------------|----------------|------|
| 访问元素 | O(1) | O(1) | 直接通过索引访问 |
| 尾部插入 | O(1) | O(n) | 扩容时需要复制所有元素 |
| 中间插入 | O(n) | O(n) | 需要移动后续元素 |
| 删除元素 | O(n) | O(n) | 需要移动后续元素 |
| 扩容操作 | O(n) | O(n) | 复制所有元素到新空间 |

#### 空间复杂度分析
- **空间复杂度**：O(n)，其中n为实际存储的元素个数
- **空间利用率**：由于动态扩容机制，可能存在一定的空间浪费

#### 扩容策略对比

| 策略 | 扩容倍数 | 优点 | 缺点 |
|------|----------|------|------|
| 倍增策略 | ×2 | 均摊时间复杂度优秀 | 可能浪费较多空间 |
| 增量策略 | +固定值 | 空间利用率高 | 扩容频繁，均摊复杂度较差 |

#### 实际应用场景
- **Vector容器**：C++ STL中的vector就是基于动态数组实现
- **ArrayList**：Java中的ArrayList也是动态数组
- **可变长度数据存储**：当数据量不确定但需要频繁随机访问时

#### 注意事项
1. **内存泄漏防护**：每次扩容后要确保释放旧内存
2. **边界检查**：所有操作都要进行参数合法性检查
3. **异常处理**：内存分配失败时要有适当的错误处理机制
4. **性能优化**：可根据实际使用场景调整扩容策略
