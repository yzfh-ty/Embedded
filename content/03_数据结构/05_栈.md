## 栈（Stack）

栈是一种特殊的线性表，只允许在一端（称为栈顶）进行插入和删除操作，遵循**后进先出（LIFO, Last In First Out）**的原则。

### 核心特性
- **操作受限**：只能在栈顶进行元素的插入（入栈/压栈）和删除（出栈/弹栈）
- **LIFO原则**：最后入栈的元素最先出栈
- **栈顶指针**：用于标识当前栈顶位置

### 应用场景
- **函数调用管理**：程序运行时的函数调用栈
- **表达式求值**：中缀表达式转后缀表达式
- **括号匹配**：检查括号是否匹配
- **撤销操作**：文本编辑器的撤销功能
- **浏览器历史**：后退功能实现

## 栈的实现方式

### 1. 顺序栈（基于数组实现）

#### 数据结构定义
```c
#define STACK_SIZE 20

struct stack {
    int data[STACK_SIZE];  // 存储栈元素的数组
    int top;               // 栈顶指针，指向栈顶元素的下一个位置
};
```

#### 初始化栈
```c
void stack_init(struct stack *stk) {
    if (stk == NULL) return;
    stk->top = 0;  // 栈顶指针初始化为0，表示空栈
}
```

#### 判空操作
```c
int stack_is_empty(const struct stack *stk) {
    if (stk == NULL) return -1;
    return stk->top == 0;
}
```

#### 判满操作
```c
int stack_is_full(const struct stack *stk) {
    if (stk == NULL) return -1;
    return stk->top == STACK_SIZE;
}
```

#### 入栈操作（压栈）
```c
int stack_push(struct stack *stk, int value) {
    if (stk == NULL) return 0;
    if (stack_is_full(stk)) return 0;  // 栈满无法入栈
  
    stk->data[stk->top++] = value;
    return 1;
}
```

#### 出栈操作（弹栈）
```c
int stack_pop(struct stack *stk, int *value) {
    if (stk == NULL || value == NULL) return 0;
    if (stack_is_empty(stk)) return 0;  // 栈空无法出栈
  
    *value = stk->data[--stk->top];
    return 1;
}
```

#### 获取栈顶元素（不删除）
```c
int stack_top(const struct stack *stk, int *value) {
    if (stk == NULL || value == NULL) return 0;
    if (stack_is_empty(stk)) return 0;
  
    *value = stk->data[stk->top - 1];
    return 1;
}
```

#### 获取栈中元素个数
```c
int stack_size(const struct stack *stk) {
    if (stk == NULL) return -1;
    return stk->top;
}
```

#### 清空栈
```c
void stack_clear(struct stack *stk) {
    if (stk == NULL) return;
    stk->top = 0;
}
```

#### 打印栈内容
```c
void stack_print(const struct stack *stk) {
    if (stk == NULL) return;
    if (stack_is_empty(stk)) {
        printf("栈为空\n");
        return;
    }
  
    printf("栈内容（从栈顶到栈底）：");
    for (int i = stk->top - 1; i >= 0; i--) {
        printf("%d ", stk->data[i]);
    }
    printf("\n");
}
```

### 2. 链式栈（基于链表实现）

#### 节点定义
```c
struct stack_node {
    int data;
    struct stack_node *next;
};

struct linked_stack {
    struct stack_node *top;  // 指向栈顶节点
    int size;                // 栈中元素个数
};
```

#### 初始化链式栈
```c
void linked_stack_init(struct linked_stack *stk) {
    if (stk == NULL) return;
    stk->top = NULL;
    stk->size = 0;
}
```

#### 判空操作
```c
int linked_stack_is_empty(const struct linked_stack *stk) {
    if (stk == NULL) return -1;
    return stk->top == NULL;
}
```

#### 入栈操作
```c
int linked_stack_push(struct linked_stack *stk, int value) {
    if (stk == NULL) return 0;
  
    struct stack_node *new_node = (struct stack_node*)malloc(sizeof(struct stack_node));
    if (new_node == NULL) return 0;  // 内存分配失败
  
    new_node->data = value;
    new_node->next = stk->top;
    stk->top = new_node;
    stk->size++;
    return 1;
}
```

#### 出栈操作
```c
int linked_stack_pop(struct linked_stack *stk, int *value) {
    if (stk == NULL || value == NULL) return 0;
    if (linked_stack_is_empty(stk)) return 0;
  
    struct stack_node *temp = stk->top;
    *value = temp->data;
    stk->top = temp->next;
    free(temp);
    stk->size--;
    return 1;
}
```

#### 获取栈顶元素
```c
int linked_stack_top(const struct linked_stack *stk, int *value) {
    if (stk == NULL || value == NULL) return 0;
    if (linked_stack_is_empty(stk)) return 0;
  
    *value = stk->top->data;
    return 1;
}
```

#### 获取栈大小
```c
int linked_stack_size(const struct linked_stack *stk) {
    if (stk == NULL) return -1;
    return stk->size;
}
```

#### 销毁栈
```c
void linked_stack_destroy(struct linked_stack *stk) {
    if (stk == NULL) return;
  
    while (stk->top != NULL) {
        struct stack_node *temp = stk->top;
        stk->top = stk->top->next;
        free(temp);
    }
    stk->size = 0;
}
```

### 两种实现方式对比

| 特性 | 顺序栈 | 链式栈 |
|------|--------|--------|
| 存储方式 | 连续内存空间 | 非连续内存空间 |
| 空间效率 | 预分配固定空间，可能浪费 | 按需分配，无空间浪费 |
| 时间复杂度 | 所有操作O(1) | 所有操作O(1) |
| 内存开销 | 无额外指针开销 | 每个节点有额外指针开销 |
| 容量限制 | 受数组大小限制 | 理论上无限制 |
| 实现复杂度 | 简单 | 相对复杂 |

### 栈的应用实例

#### 1. 括号匹配检查
```c
int is_brackets_matched(const char *expr) {
    struct stack stk;
    stack_init(&stk);
  
    for (int i = 0; expr[i] != '\0'; i++) {
        char ch = expr[i];
      
        if (ch == '(' || ch == '[' || ch == '{') {
            stack_push(&stk, ch);
        } else if (ch == ')' || ch == ']' || ch == '}') {
            if (stack_is_empty(&stk)) return 0;
          
            int top;
            stack_pop(&stk, &top);
          
            if ((ch == ')' && top != '(') ||
                (ch == ']' && top != '[') ||
                (ch == '}' && top != '{')) {
                return 0;
            }
        }
    }
  
    return stack_is_empty(&stk);
}
```

### 栈的性能分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 入栈 | O(1) | O(1) |
| 出栈 | O(1) | O(1) |
| 获取栈顶 | O(1) | O(1) |
| 判空/判满 | O(1) | O(1) |

### 注意事项
1. **栈溢出处理**：顺序栈需要检查容量限制
2. **内存管理**：链式栈需要及时释放内存避免泄漏
3. **边界条件**：空栈时不能出栈，满栈时不能入栈
4. **异常处理**：指针为空、内存分配失败等情况需要妥善处理
