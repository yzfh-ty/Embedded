## 递归 (Recursion)

### 定义

递归是一种重要的编程思想和算法设计技巧。函数调用自身的过程即为递归。它通过将一个大问题逐步分解为同类型的子问题来解决问题。

> *递归就像俄罗斯套娃：打开一个娃娃，里面还有一个更小的同样的娃娃。最终会到达最小单位（基线条件），然后逐层返回结果。*

### 基本要素

1. **基线条件（Base Case）**：
   - 递归终止的条件，防止无限递归。
   - 通常是处理最简化、可以直接求解的情况。
 
2. **递归条件（Recursive Case）**：
   - 将当前问题转换成更小规模的同类问题。
   - 使得原问题向基线条件逼近。

### 递归执行特点

- 递归函数的调用会在栈中保存每层的状态信息（局部变量、参数等）。
- 调用过程形成“递归下降”，返回过程形成“回溯上升”。
- 每次递归都相当于一次函数压栈操作。

#### 示例图示：计算 n!（阶乘）

```
factorial(n) => n * factorial(n - 1)
...
直到 factorial(0) 或 factorial(1) = 1 （基线条件）
```

### 应用场景

递归常用于解决具有自相似结构的问题，例如：

| 场景               | 典型例子                     |
|--------------------|------------------------------|
| 数学计算           | 阶乘、斐波那契数列           |
| 树与图遍历         | 深度优先搜索（DFS）          |
| 分治策略           | 快速排序、归并排序           |
| 字符串处理         | 回文判断、括号匹配           |
| 动态规划基础实现   | 斐波那契、最大公共子序列     |

### 示例一：递归实现 n 的阶乘

```c
int factorial(int n) {
    if (n <= 1) return 1;  // 基线条件
    return n * factorial(n - 1);  // 递归条件
}
```

> 执行流程举例：`factorial(4)` → `4 * factorial(3)` → ... → `4 * 3 * 2 * 1 = 24`

### 示例二：递归累加 1 到 n

```c
int recursion_sum(int n) {
    if (n <= 0) return 0; 
    return n + recursion_sum(n - 1);
}
```

> 示例：`recursion_sum(3)` = `3 + 2 + 1 + 0 = 6`

###  递归的缺点

- 调用过多可能造成栈溢出（Stack Overflow）
- 若存在重复子问题，则效率低（可使用备忘录优化）

### 递归 VS 循环

| 对比维度 | 递归                          | 循环                        |
|----------|-------------------------------|-----------------------------|
| 实现方式 | 函数调用自身                  | 使用循环关键字（for/while） |
| 空间开销 | 高（栈帧积累）                | 低（常量空间）              |
| 可读性   | 自然表达复杂问题              | 易于调试和直观分析          |
| 适用场景 | 树、图、分治等问题            | 数值累计、遍历场景          |

### 优化递归方法

1. **尾递归优化（Tail Recursion Optimization）**
   - 编译器可以将其优化为循环形式，避免栈溢出。
   ```c
   int sum_tail_rec(int n, int acc) {
       if (n <= 0) return acc;
       return sum_tail_rec(n - 1, acc + n);
   }
   ```

2. **记忆化搜索（Memoization）**
   - 对递归中已解出的子问题缓存，提升效率（如动态规划前置技术）。
 
3. **转换为迭代**
   - 使用显式栈模拟递归行为，控制资源消耗。
   ```c
   #include <stdio.h>
   void iterative_factorial(int n) {
       int result = 1;
       for (int i = 1; i <= n; i++) result *= i;
       printf("Iterative: %d! = %d\n", n, result);
   }
   ```

### 递归经典例题

#### 示例一：Fibonacci 数列（简单递归实现）

```c
int fib_recursive(int n) {
    if (n <= 1) return n;
    return fib_recursive(n - 1) + fib_recursive(n - 2);
}
```

> 注意：该方法指数复杂度，不推荐用于大数字运算。

#### 示例二：二叉树的先序遍历

```c
struct bnode {
    int data;
    struct bnode *left;
    struct bnode *right;
};

void preorder_traversal(struct bnode* root) {
    if (root != NULL) {
        printf("%d ", root->data);       // 访问根节点
        preorder_traversal(root->left);  // 遍历左子树
        preorder_traversal(root->right); // 遍历右子树
    }
}
```
