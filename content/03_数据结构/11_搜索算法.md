# 搜索算法 (Search Algorithms)

搜索算法是一类用于在数据集合中查找特定元素或路径的通用方法。根据数据的组织方式和查询策略，搜索可以分为**线性搜索、二分搜索、深度优先搜索、广度优先搜索**等多种类型。

## 顺序查找（Linear Search / Sequential Search）

### 适用条件
- 数据无需预先排序。
- 可用于数组、链表等线性结构。
- 数据量较小时性能可接受。

### 时间复杂度
- 最好：O(1)（目标在首位）
- 平均：O(n)
- 最坏：O(n)（未找到或在末尾）

### 示例代码

```c
int linear_search(int arr[], int size, int target) {
    for (int i = 0; i < size; i++) {
        if (arr[i] == target)
            return i;
    }
    return -1;  // 未找到
}
```

### 优点
- 实现简单直观
- 不依赖数据是否有序

### 缺点
- 在大数据集中效率较低

## 二分查找（Binary Search）

### 适用条件
- 数据必须是**已排序**的数组。
- 支持随机访问（如数组索引）。

### 时间复杂度
- O(log n)

### 工作原理
1. 初始化左右边界：`left = 0`, `right = size - 1`
2. 中间值：`mid = (left + right) / 2`
3. 比较中间值：
   - 相等 → 返回索引
   - 目标小 → `right = mid - 1`
   - 目标大 → `left = mid + 1`
4. 循环直到 `left <= right`

### 示例代码

```c
int binary_search(int arr[], int size, int target) {
    int left = 0;
    int right = size - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target)
            return mid;
        else if (arr[mid] > target)
            right = mid - 1;
        else
            left = mid + 1;
    }
    return -1;
}
```

> 提示：使用 `left + (right - left) / 2` 可防止整数溢出。

### 递归版本

```c
int binary_search_recursive(int arr[], int left, int right, int target) {
    if (left > right) return -1;
    int mid = left + (right - left) / 2;
    if (arr[mid] == target)
        return mid;
    else if (arr[mid] > target)
        return binary_search_recursive(arr, left, mid - 1, target);
    else
        return binary_search_recursive(arr, mid + 1, right, target);
}
```

### 优点
- 效率高，适用于大量有序数据

### 缺点
- 要求数据预先排序
- 不适合动态插入/删除频繁的结构

## 深度优先搜索（DFS — Depth First Search）

### 定义
一种遍历或搜索树/图的方法，沿着某条路径尽可能深入，直到无法继续再回溯。

### 应用场景
- 图/树的所有路径生成
- 迷宫寻路
- 拓扑排序
- 解决八皇后、数独等问题

### 实现方式
#### 1. 递归实现（适用于简单结构）

```c
void dfs_recursive(struct bnode* node) {
    if (node == NULL) return;
    printf("%d ", node->data);
    dfs_recursive(node->left);
    dfs_recursive(node->right);
}
```

#### 2. 栈实现（非递归版本）

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct StackNode {
    struct bnode* treeNode;
    struct StackNode* next;
} StackNode;

void push(StackNode** top, struct bnode* node) {
    StackNode* new_node = (StackNode*)malloc(sizeof(StackNode));
    new_node->treeNode = node;
    new_node->next = *top;
    *top = new_node;
}

struct bnode* pop(StackNode** top) {
    if (*top == NULL) return NULL;
    StackNode* temp = *top;
    struct bnode* node = temp->treeNode;
    *top = temp->next;
    free(temp);
    return node;
}

void dfs_iterative(struct bnode* root) {
    if (!root) return;
    StackNode* stack = NULL;
    push(&stack, root);

    while (stack) {
        struct bnode* node = pop(&stack);
        if (node) {
            printf("%d ", node->data);
            push(&stack, node->right);
            push(&stack, node->left);
        }
    }
}
```

## 广度优先搜索（BFS — Breadth First Search）

### 定义
按层级依次访问节点，每层从左至右遍历。

### 应用场景
- 层级遍历（Level Order Traversal）
- 寻找最短路径（无权图）
- 广播通信模型模拟

### 实现方式（基于队列）

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct QueueNode {
    struct bnode* treeNode;
    struct QueueNode* next;
} QueueNode;

void enqueue(QueueNode** rear, struct bnode* node) {
    QueueNode* new_node = (QueueNode*)malloc(sizeof(QueueNode));
    new_node->treeNode = node;
    new_node->next = NULL;
    if (*rear != NULL)
        (*rear)->next = new_node;
    *rear = new_node;
}

struct bnode* dequeue(QueueNode** front) {
    if (*front == NULL) return NULL;
    QueueNode* temp = *front;
    struct bnode* node = temp->treeNode;
    *front = temp->next;
    free(temp);
    return node;
}

void bfs_iterative(struct bnode* root) {
    if (!root) return;

    QueueNode* front = NULL;
    QueueNode* rear = NULL;

    enqueue(&rear, root);
    while (front != NULL) {
        struct bnode* current = dequeue(&front);
        printf("%d ", current->data);
        if (current->left) enqueue(&rear, current->left);
        if (current->right) enqueue(&rear, current->right);
    }
}
```

## 总结对比：常见搜索算法一览

| 算法名称     | 数据结构要求 | 时间复杂度 | 最佳用途                     |
|--------------|---------------|-------------|-------------------------------|
| 线性查找     | 任意         | O(n)        | 无序、静态数据                |
| 二分查找     | 已排序数组   | O(log n)    | 大型有序快速查找              |
| DFS（递归）  | 图、树       | O(V + E)    | 路径探索、拓扑排序            |
| DFS（栈）    | 图、树       | O(V + E)    | 与递归相同，但规避栈溢出风险  |
| BFS（队列）  | 图、树       | O(V + E)    | 最短路径、层级遍历            |
