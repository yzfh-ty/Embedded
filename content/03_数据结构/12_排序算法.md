# 🔄 排序算法（Sorting Algorithms）

## 🧾 概述

排序是将一组数据按照某种既定顺序（升序或降序）排列的过程。排序广泛应用于数据检索、数据分析、优化结构等领域。

不同排序算法在时间和空间复杂度上有显著差异。因此，选择合适的算法取决于应用场景和性能需求。

---

## 🧩 排序算法分类

按稳定性可分为：
- **稳定排序**：相等元素的相对位置不改变（如冒泡、插入）
- **不稳定排序**：可能会改变相等元素的相对位置（如快排、堆排序）

按实现方式可分为：
- **比较排序**：通过比较元素大小进行排序（大多数都是）
- **非比较排序**：如计数排序、桶排序等，效率更高但有特殊要求

---

## ✨ 典型排序算法详解

---

### 1️⃣ 冒泡排序（Bubble Sort）

#### 🧠 原理
重复遍历列表，比较每对相邻项。若发现逆序则交换。一轮下来，最大值沉底。

#### ⏱ 时间复杂度
- 最坏/平均：O(n²)
- 最好：O(n) —— 已排序
- 空间复杂度：O(1)

#### 🌰 示例代码

```c
void bubble_sort(int arr[], int len) {
    for (int i = 0; i < len - 1; ++i) {
        int swapped = 0;  // 优化标记，已排序时提前退出
        for (int j = 0; j < len - 1 - i; ++j) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = 1;
            }
        }
        if (!swapped) break;  // 若本轮未交换过数据，说明已经有序
    }
}
```

#### 🔍 特点
- 思路直观易懂，适合教学演示
- 稳定排序
- 适合教学演示但不适合大规模数据

---

### 2️⃣ 插入排序（Insertion Sort）

#### 🧠 原理
像打牌一样逐步整理牌面：每次取一个元素，插入到已排序数组中的合适位置。

#### ⏱ 时间复杂度
- 最坏：O(n²)
- 最好：O(n)（数组已排序）
- 平均：O(n²)

#### 🌰 示例代码

```c
void insertion_sort(int arr[], int len) {
    for (int i = 1; i < len; ++i) {
        int key = arr[i];   // 当前待插入的元素
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}
```

#### 🔍 特点
- 对小规模或基本有序数据效率高
- 是**稳定排序**
- 常作为其他排序算法的一个子过程（如 QuickSort 尾部调用 Insertion）

---

### 3️⃣ 选择排序（Selection Sort）

#### 🧠 原理
每次从未排序部分选出最小值放到当前排序区段的末尾。

#### ⏱ 时间复杂度
- 永远是 O(n²)，无论初始序列
- 不稳定排序（如数组 [4, 4, ..., 4, 5]，前几个相同值会被打乱顺序）

#### 🌰 示例代码

```c
void selection_sort(int arr[], int len) {
    for (int i = 0; i < len - 1; ++i) {
        int min_index = i;
        for (int j = i + 1; j < len; ++j) {
            if (arr[j] < arr[min_index])
                min_index = j;
        }
        if (min_index != i) {
            int temp = arr[i];
            arr[i] = arr[min_index];
            arr[min_index] = temp;
        }
    }
}
```

#### 🔍 特点
- 交换次数少，适合内存写操作昂贵的场景（如 Flash/磁盘）
- 实现简单
- 不稳定排序

---

### 4️⃣ 快速排序（Quick Sort）

#### 🧠 原理
采用分治策略：选取一个“基准”（pivot），将数组划分为小于基准和大于基准的部分，分别递归地进行快速排序。

#### ⏱ 时间复杂度
- 平均情况：O(n log n)
- 最坏情况：O(n²) → 当数据已经有序且每次都选最边元素作为 pivot

#### 🌰 示例代码

```c
void quick_sort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quick_sort(arr, low, pi - 1);     // 左子数组
        quick_sort(arr, pi + 1, high);    // 右子数组
    }
}

int partition(int arr[], int low, int high) {
    int pivot = arr[high];               // 选择最后一个元素为 pivot
    int i = (low - 1);                   // 小于 pivot 的区域边界

    for (int j = low; j <= high - 1; j++) {
        if (arr[j] < pivot) {
            i++;                          // 扩展小于 pivot 区域
            swap(&arr[i], &arr[j]);      // 交换到左边
        }
    }
    swap(&arr[i + 1], &arr[high]);       // 把 pivot 放在正确位置
    return (i + 1);
}
```

#### 🔍 特点
- 广泛应用于工程实践中（如 C 库的 `qsort()`）
- 平均效率高
- **不稳定排序**
- 可通过优化选取 pivot（如随机法、三数取中法）提升性能

### 5️⃣ 归并排序（Merge Sort）

#### 🧠 原理
分治思想：将数组不断二分直至只剩一个元素，再合并两个已排序的数组，直到整个数组有序。

#### ⏱ 时间复杂度
- 永远是 O(n log n)，最稳定
- 空间复杂度 O(n)

#### 🌰 示例代码（核心逻辑）

```c
void merge_sort(int arr[], int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        merge_sort(arr, left, mid);
        merge_sort(arr, mid + 1, right);
        merge(arr, left, mid, right);
    }
}

void merge(int arr[], int left, int mid, int right) {
    int n1 = mid - left + 1;
    int n2 = right - mid;
    int L[n1], R[n2];

    for (int i = 0; i < n1; i++) L[i] = arr[left + i];
    for (int j = 0; j < n2; j++) R[j] = arr[mid + 1 + j];

    int i = 0, j = 0, k = left;
    while (i < n1 && j < n2)
        arr[k++] = (L[i] <= R[j]) ? L[i++] : R[j++];
    while (i < n1) arr[k++] = L[i++];
    while (j < n2) arr[k++] = R[j++];
}
```

#### 🔍 特点
- 稳定排序
- 时间复杂度始终 O(n log n)
- 适合外部排序，因数据访问模式良好

## 📊 常见排序算法比较汇总

| 算法       | 最好时间复杂度 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 | 推荐场景                             |
|------------|----------------|----------------|----------------|-------------|--------|---------------------------------------|
| 冒泡排序   | O(n)           | O(n²)          | O(n²)          | O(1)        | 稳定   | 小规模、演示、教学                   |
| 插入排序   | O(n)           | O(n²)          | O(n²)          | O(1)        | 稳定   | 小规模、部分有序的数据               |
| 选择排序   | O(n²)          | O(n²)          | O(n²)          | O(1)        | 不稳定 | 写代价大但读代价小（如 Flash）       |
| 快速排序   | O(n log n)     | O(n log n)     | O(n²)          | O(log n)    | 不稳定 | 数据随机性好时表现优异              |
| 归并排序   | O(n log n)     | O(n log n)     | O(n log n)     | O(n)        | 稳定   | 数据量大、需稳定排序、外部排序等场合 |
