# 🌳 树（Tree）

## 📘 基础定义

树是一种层次化的非线性数据结构，由节点组成，其中每个节点都可以拥有多个子节点，但只有一个父节点（除了根节点）。

---

## 📚 术语介绍

| 术语         | 含义                                                         |
|--------------|--------------------------------------------------------------|
| 节点（Node） | 树的最小单元，包含数据和若干指向其他节点的链接               |
| 根节点（Root） | 整棵树的顶端节点，无父节点                                   |
| 父节点（Parent） | 上级节点，有一个直接儿子                                   |
| 子节点（Child） | 直接下级节点                                               |
| 兄弟节点（Sibling） | 具有同一个父节点的多个节点                               |
| 度（Degree） | 某节点具有的子树个数                                         |
| 叶子节点（Leaf） | 没有子节点的节点                                           |
| 深度（Depth） | 根节点到某节点的路径长度（起点为 0）                        |
| 高度（Height） | 从当前节点到最低叶子的最大路径长度                         |
| 路径（Path） | 连续访问的节点序列                                            |

---

## 📐 特殊类型的树

### 1️⃣ 满二叉树（Full Binary Tree）
- 所有节点都有 0 或 2 个子节点
- 每一层都达到最大节点数

### 2️⃣ 完全二叉树（Complete Binary Tree）
- 除了最后一层外，每层都被完全填满
- 最底一层节点靠左排列

### 3️⃣ 平衡二叉树（AVL Tree）
- 左右子树的高度差不超过 1
- 插入删除后会自动调整保持平衡

### 4️⃣ 二叉搜索树（BST - Binary Search Tree）
- 左子树所有节点 < 父节点
- 右子树所有节点 ≥ 父节点
- 中序遍历得到有序序列

### 5️⃣ 哈夫曼树（Huffman Tree）
- 用于构建最优前缀编码
- 每个字符对应一个叶子节点
- 构造过程中总是合并频率最小的两棵树

| 操作     | 功能描述                         |
|----------|----------------------------------|
| 插入     | 在树中添加一个新节点             |
| 删除     | 删除指定节点                    |

| 遍历     | 有多种方式（前中后层次）        |
| 修改     | 更改某个节点的内容              |

## 🔁 二叉树的遍历方式

### 1️⃣ 前序遍历（Pre-Order）
- 先访问根节点
- 再递归遍历左子树
- 再递归遍历右子树

```c
void pre_order(struct bnode *root) {
    if (root != NULL) {
        printf("%d ", root->data);
        pre_order(root->left);
        pre_order(root->right);
    }
}
```

### 2️⃣ 中序遍历（In-Order）
- 先遍历左子树
- 再访问根节点
- 再遍历右子树

```c
void in_order(struct bnode *root) {
    if (root != NULL) {
        in_order(root->left);
        printf("%d ", root->data);
        in_order(root->right);
    }
}
```

### 3️⃣ 后序遍历（Post-Order）
- 先遍历左子树
- 再遍历右子树
- 最后访问根节点

```c
void post_order(struct bnode *root) {
    if (root != NULL) {
        post_order(root->left);
        post_order(root->right);
        printf("%d ", root->data);
    }
}
```

### 4️⃣ 层序遍历（Level Order）
- 按层次顺序，逐层从左往右访问
- 用队列实现

```c
void level_order(struct bnode *root) {
    if (!root) return;

    Queue* q = create_queue();
    enqueue(q, root);

    while (!is_empty(q)) {
        struct bnode* current = dequeue(q);
        printf("%d ", current->data);
        if (current->left) enqueue(q, current->left);
        if (current->right) enqueue(q, current->right);
    }

    destroy_queue(q);
}
```

## 📦 二叉树的存储结构

### 顺序存储（数组实现，适用于完全二叉树）

- 优点：节约指针空间
- 缺点：对于一般的二叉树，浪费空间较大

### 链式存储（常用）

```c
struct bnode {
    int data;
    struct bnode *left;
    struct bnode *right;
};
```

## ⚠️ 易混淆的知识点说明（FAQ式）

### Q1: 什么是“路径长度”？与“节点数”有什么关系？
A1: “路径长度”指的是走过的路径的段数，即节点连接数。例如从 A 到 B 共经历三次移动，则长度为 3；而节点数是路径上总共出现的节点数（包括起点终点）。

### Q2: 平衡二叉树一定是完全二叉树吗？
A2: 不一定。AVL 树强调高度差 ≤ 1，不一定符合完全二叉树结构（最后一层不一定连续靠左）。

### Q3: 如何删除 BST 中的一个节点？
A3: BST 删除需考虑三种情况：
- 是叶子节点 → 直接删除
- 有单个子树 → 子树继承其位置
- 有两个子树 → 找到前驱（或后继）节点替代，并递归删除该前驱节点

### 🧠 经典树操作示例

#### 问题：计算二叉树的高度

```c
int height(struct bnode* root) {
    if (!root) return 0;
    int left_height = height(root->left);
    int right_height = height(root->right);
    return ((left_height > right_height ? left_height : right_height) + 1);
}
```
