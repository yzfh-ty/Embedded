# 📁 文件操作（File Operations）

## 📘 基础概念

文件是存储在外部存储设备（如磁盘）上的一组相关数据的集合。在程序运行过程中，可通过文件操作接口对文件进行读取、写入、修改、删除等操作。

C语言标准库提供一组完整的文件操作函数（位于 `<stdio.h>` 中），使得我们能够方便地操作磁盘上的文件。

---

## 📂 文件类型

### 1️⃣ 文本文件（Text File）
- 数据以 ASCII 或 Unicode 格式存储
- 可以被人类直接阅读
- 如 `.txt`, `.c`, `.csv`

### 2️⃣ 二进制文件（Binary File）
- 数据以原始字节流形式存储
- 不能直接读取内容，通常由程序处理
- 如 `.exe`, `.jpg`, `.dat`

---

## 🔧 文件操作流程（通用三步走）

1. **打开文件（fopen）**
2. **操作文件（读写）**
3. **关闭文件（fclose）**

---

## 📌 文件操作函数详解

### 1️⃣ 打开文件：`fopen()`

```c
FILE *fopen(const char *filename, const char *mode);
```

| 模式 | 含义 |
|------|------|
| `"r"`  | 只读打开文本文件（不存在则失败） |
| `"w"`  | 写入文本文件，如存在则清空内容 |
| `"a"`  | 追加写入，末尾添加数据 |
| `"rb"` | 只读二进制 |
| `"wb"` | 写入二进制 |
| `"ab"` | 追加写入二进制 |
| `"r+"` | 读写打开，从开头 |
| `"w+"` | 创建或擦除已有文件进行读写 |
| `"a+"` | 打开并在末尾追加读写 |

**示例：**

```c
FILE *fp;
fp = fopen("example.txt", "r");
if (fp == NULL) {
    printf("无法打开文件\n");
    exit(EXIT_FAILURE);
}
// ... 操作
fclose(fp); // 关闭文件
```

---

### 2️⃣ 关闭文件：`fclose()`

```c
int fclose(FILE *stream);
```

- 返回值：
  - 成功返回 0
  - 失败返回 EOF

---

### 3️⃣ 读取文件内容

#### ➤ 字符级读取：`fgetc()`

```c
int fgetc(FILE *stream);
```

示例：

```c
char ch;
while ((ch = fgetc(fp)) != EOF) {
    putchar(ch);  // 输出到屏幕
}
```

> `EOF` 是一个宏定义，通常表示 -1。

#### ➤ 行级读取：`fgets()`

```c
char *fgets(char *str, int size, FILE *stream);
```

示例：

```c
char buffer[100];
while (fgets(buffer, sizeof(buffer), fp) != NULL) {
    printf("%s", buffer);
}
```

#### ➤ 格式化读取：`fscanf()`

类似 `scanf()`，只不过从文件中读取：

```c
int num;
fscanf(fp, "%d", &num);
```

---

### 4️⃣ 写入文件内容

#### ➤ 字符级写入：`fputc()`

```c
int fputc(int ch, FILE *stream);
```

示例：

```c
fputc('A', fp);
```

#### ➤ 字符串写入：`fputs()`

```c
int fputs(const char *str, FILE *stream);
```

示例：

```c
fputs("Hello World\n", fp);
```

#### ➤ 格式化输出：`fprintf()`

类似 `printf()`，不过输出到文件中：

```c
fprintf(fp, "Value = %d\n", value);
```

#### ➤ 块数据写入：`fwrite()`

```c
size_t fwrite(const void *ptr, size_t size, size_t count, FILE *stream);
```

示例：

```c
struct Student {
    int id;
    char name[50];
} s = {1, "Alice"};
fwrite(&s, sizeof(struct Student), 1, fp);
```

---

### 5️⃣ 移动文件指针位置

#### ➤ 设置当前位置：`fseek()`

```c
int fseek(FILE *stream, long offset, int origin);
```

| origin 参数 | 含义           |
|-------------|----------------|
| `SEEK_SET`  | 文件开头       |
| `SEEK_CUR`  | 当前位置       |
| `SEEK_END`  | 文件结尾       |

#### ➤ 获取当前位置：`ftell()`

```c
long ftell(FILE *stream);
```

#### ➤ 将指针移回开头：`rewind()`

```c
void rewind(FILE *stream);
```

---

## ⚠️ 常见操作注意事项

### ❗ 忘记关闭文件的风险
- 系统资源未释放
- 数据可能未真正写入磁盘（缓冲区问题）
- 文件句柄泄露可能导致打开失败

### ❗ 文本 vs 二进制模式差异
- 对于 `"r"` 和 `"w"` 模式，不同平台会自动处理换行符差异
- 对二进制文件使用 `"rb"` / `"wb"` 更安全（Windows 中尤其注意）

### ❗ 缓冲机制说明
- 编写数据到缓冲区，不一定立即写入磁盘
- 使用 `fflush(fp)` 强制刷新缓存
- `fclose()` 会内部调用 `fflush()`

## 🧪 文件操作实战示例

### 🟦 示例一：读取整块文本文件

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    FILE *fp = fopen("input.txt", "r");
    if (fp == NULL) {
        perror("File opening failed");
        return EXIT_FAILURE;
    }

    char buffer[256];
    while (fgets(buffer, sizeof(buffer), fp)) {
        printf("%s", buffer);
    }

    fclose(fp);
    return 0;
}
```

---

### 🟦 示例二：二进制读写结构体

```c
#include <stdio.h>
#include <stdlib.h>

struct Record {
    int id;
    char name[20];
};

int main() {
    FILE *fp = fopen("data.dat", "wb+");
    if (fp == NULL) {
        printf("Cannot open file\n");
        return 1;
    }

    struct Record r = {101, "Tom"};
    fwrite(&r, sizeof(r), 1, fp);

    rewind(fp); // 回到文件开头再读
    struct Record r2;
    fread(&r2, sizeof(r2), 1, fp);
    printf("ID: %d, Name: %s\n", r2.id, r2.name);

    fclose(fp);
    return 0;
}
```
