# 哈希（Hash）

## 基础概念

哈希是一种通过特定算法将任意长度的输入（关键字）映射为固定长度输出（哈希值）的技术。目标是实现快速查找、存储和检索。

## 哈希的核心作用

- 快速访问数据（常数时间 O(1)）
- 提供数据完整性校验（如 MD5、SHA）
- 实现密码加密基础方法
- 解决字符串匹配等高效问题

## 哈希函数设计原则

好的哈希函数应具备以下特性：

1. **确定性**：相同的输入永远映射为相同结果
2. **均匀分布**：尽量平均分布在哈希表空间内
3. **快速计算**：复杂度低，效率高
4. **雪崩效应**：微小输入变化带来剧烈输出变化（适用于加密）

## 常见哈希函数设计方法

### 直接定址法（Linear Probing）
```c
hash(key) = key 或 hash(key) = a*key + b
```
适用于关键字分布均匀且已知范围有限时。

### 除留余数法（Modulo Method）
```c
hash(key) = key % TABLE_SIZE
```
简单实用，但必须选择合适的质数作为表长，可减少冲突概率。

> 💡 推荐：使用接近两倍于预期元素数量的质数作哈希表大小。

### 数字分析法
分析关键字各位上的分布情况，提取分布较均匀的部分组成哈希地址（适合静态数据集）。

### 平方取中法
```c
hash(key) = (key * key) >> bits;  // 取平方中间几位
```

### 折叠法（适用于长整数或字符串）
将关键字分割成几部分，叠加相加后取模。

```c
// 如关键字为："12345678"
// 分割为 "123" + "456" + "78"
// sum = 123 + 456 + 78 = 657 => hash = 657 % TABLE_SIZE
```

### 字符串哈希（ELF Hash / DJB Hash）
常用于字符串的唯一标识，典型代表有：

#### DJB Hash（简单流行）

```c
unsigned int djb_hash(const char *str) {
    unsigned int hash = 5381;
    int c;
    while ((c = *str++))
        hash = ((hash << 5) + hash) + c; /* hash * 33 + c */
    return hash;
}
```

#### ELF Hash（Unix 系统常用）

```c
unsigned int elf_hash(const char *str) {
    unsigned int h = 0, g;
    while (*str) {
        h = (h << 4) + *str++;
        if ((g = h & 0xF0000000))
            h ^= g >> 24;
        h &= ~g;
    }
    return h;
}
```

## 哈希冲突及其处理策略

由于哈希函数压缩了无限大的输入空间到有限的输出空间，必然会有多个关键字映射到了同一个位置 —— 这就是**冲突（Collision）**。

### 处理哈希冲突的方法：

#### 开放寻址法（Closed Hashing）

在发生冲突时，依次探查下一个可用空位置。具体方式包括：

##### 线性探测（Linear Probing）
依次向后寻找空位：

```c
pos = (hash(key) + i) % TABLE_SIZE
```

缺陷：
- 易产生**一次聚集（Primary Clustering）**

##### 二次探测（Quadratic Probing）
采用平方偏移避免主聚集：

```c
pos = (hash(key) + i*i) % TABLE_SIZE
```

限制：
- 必须满足 `TABLE_SIZE` 是 2 的幂或者满足特定条件才保证所有槽都能被遍历

##### 双重哈希（Double Hashing）
用第二个函数计算步长：

```c
pos = (hash1(key) + i * hash2(key)) % TABLE_SIZE
```

例如：
```c
hash1(key) = key % TABLE_SIZE
hash2(key) = 7 - (key % 7)  // 另一个互质的质数
```

优点：
- 减少聚集现象，性能较优

#### 链地址法（Chaining / Open Hashing）
把冲突元素用链表串起来，统一存放在同一个位置。

##### 结构定义：
```c
struct node {
    int key;
    struct node* next;
};

struct hash_table {
    int size;
    struct node** table;
};
```

##### 插入示例：
```c
void insert(struct hash_table *ht, int key) {
    int index = key % ht->size;
    struct node *new_node = malloc(sizeof(struct node));
    new_node->key = key;
    new_node->next = ht->table[index];
    ht->table[index] = new_node;
}
```

优点：
- 简单易实现
- 适用于动态增删操作频繁的情况

## 哈希表的设计优化方向

| 优化方向     | 方案说明 |
|--------------|----------|
| 负载因子控制 | α = 元素数 / 表长，尽量≤0.75 |
| 自动扩容     | 当负载因子超限时增大容量并迁移旧数据 |
| 动态内存管理 | 支持删除操作时清理空链 |
| 冲突处理改进 | 混合使用线性探查+链地址法 |
| 性能监控指标 | 平均查找长度 ASL 等数据记录 |

## 哈希的应用场景

| 应用领域             | 典型例子                          |
|----------------------|-----------------------------------|
| 字典 / 映射结构     | HashMap, Map                     |
| 缓存策略            | LRU Cache, Redis Hashes          |
| 密码学安全           | SHA-256, PBKDF2                  |
| 数据去重             | 判定是否存在重复内容             |
| 网络协议识别         | IP地址转换表                     |
| 搜索引擎索引构建     | 倒排索引                         |

## 关于哈希的安全性问题（进阶）

尽管哈希在搜索等方面非常高效，但在密码学应用中需注意：

| 哈希算法        | 是否适用密码存储 | 安全程度 |
|-----------------|------------------|-----------|
| MD5             | ❌ 不推荐         | 低        |
| SHA-1           | ⚠️ 勉强可用       | 中        |
| SHA-2系列(SHA256)| ✅ 推荐           | 高        |
| bcrypt/scrypt   | ✅ 加盐慢哈希     | 非常高    |

> ⚠️ 用于认证系统的密码哈希必须加 Salt（盐值）防止彩虹表攻击。

### 实战：简易哈希表（开放寻址 - 线性探测）

```c
#define TABLE_SIZE 13

int hash_table[TABLE_SIZE];
int EMPTY = -1;  // 空标记
int DELETED = -2; // 删除标记

void init_table() {
    for (int i = 0; i < TABLE_SIZE; i++) {
        hash_table[i] = EMPTY;
    }
}

int hash(int key) {
    return key % TABLE_SIZE;
}

int insert(int key) {
    int index = hash(key);
    int i = 0;
    while (i < TABLE_SIZE) {
        int pos = (index + i) % TABLE_SIZE;
        if (hash_table[pos] == EMPTY || hash_table[pos] == DELETED) {
            hash_table[pos] = key;
            return 1;
        } else if (hash_table[pos] == key) {
            return 0;  // Already exists
        }
        i++;
    }
    return 0;  // Table full
}

int search(int key) {
    int index = hash(key);
    int i = 0;
    while (i < TABLE_SIZE) {
        int pos = (index + i) % TABLE_SIZE;
        if (hash_table[pos] == key)
            return pos;
        if (hash_table[pos] == EMPTY)
            return -1;
        i++;
    }
    return -1;
}
```
