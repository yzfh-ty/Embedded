## 预处理与宏定义

### 文件包含

- **`#include <头文件>`**
  - 系统头文件一般存放于标准库路径，优先从系统目录中搜索。
  - 编译时可通过 `-I<目录>` 指定额外头文件查找目录：
    ```shell
    gcc -I/home/weimz/inc  # 指定额外头文件搜索目录 [1]
    ```

- **`#include "头文件"`**
  - 先从当前源文件所在目录搜索，如果没有找到再到系统目录搜索 [1]。

### 条件编译

用于控制代码在不同平台或不同条件下是否被编译。

```c
#if 常量表达式
#elif 常量表达式
#else
#endif

#ifdef 宏名          // 如果宏已定义，则编译后续代码 [1]
#ifndef 宏名         // 如果宏未定义，则编译后续代码 [1][2]
```

#### defined 操作符
- 与 `#if` 或 `#elif` 配合使用，判断某个宏是否定义。
- 可用于更复杂的条件表达式判断。
```c
#if defined(DEBUG) && !defined(RELEASE)
    printf("Debug 模式下执行\n");
#endif
```

#### GCC 编译器参数 `-D`
可通过命令行在编译时定义宏 [5]：
```shell
gcc -D宏名            # 默认值为 1
gcc -D宏名=宏值       # 明确指定宏的值
```
例如：
```shell
gcc -DCHINESE         # 等同 #define CHINESE 1
gcc -DVERSION=2.0     # 等同 #define VERSION 2.0
```

### 宏定义（MACRO）

#### 不带参数的宏定义
用于定义简单的常量：
```c
#define PI 3.1415926
#define MAX_BUFFER_SIZE 1024
```

#### 带有参数的宏定义
用于模拟函数，但不涉及函数调用开销。
```c
#define AREA(r) (3.14*(r)*(r))               // 圆面积 [1]
#define MAX(a,b) ((a)>(b)?(a):(b))          // 两数最大值 [2]
#define SQUARE(x) ((x)*(x))                 // 平方 [2]
```

#### 特殊字符处理

| 字符 | 作用 | 示例 |
|------|------|------|
| `#`  | 将宏参数转换为字符串 | `#define STR(x) #x` => `STR(hello)` 生成 `"hello"` |
| `##` | 连接宏参数 | `#define CONCAT(a,b) a##b` => `CONCAT(var,1)` 生成 `var1` |

代码示例 [1][3]：
```c
#define STRINGIFY(x) #x              // 变为字符串
#define CONCAT(a,b) a##b             // 参数拼接
#define DECLARE_VAR(type,name) type var_##name

int main() {
    int var_count = 10;
    printf("变量名: %s\n", STRINGIFY(var_count));  // 输出: "var_count"
    int CONCAT(my,num) = 42;                       // 相当于 int mynum = 42;
    DECLARE_VAR(int, age) = 25;                    // 相当于 int var_age = 25;
    return 0;
}
```

> **注意**：宏展开是文本替换，不进行类型检查，因此需小心使用括号以避免运算优先级问题。

### 系统预定义宏

这些宏由编译器自动定义，提供一些编译期信息 [1][3]：

| 宏名称        | 含义                             |
|---------------|----------------------------------|
| `__DATE__`    | 编译日期，格式："Mmm dd yyyy"     |
| `__TIME__`    | 编译时间，格式："hh:mm:ss"        |
| `__FILE__`    | 当前文件名                       |
| `__LINE__`    | 当前行号                         |
| `__func__`    | 当前函数名（C99起支持）           |
| `__FUNCTION__`| 某些编译器支持的扩展函数名         |
| `__cplusplus` | 若为C++编译则定义                |
| `__STDC__`    | 若为符合标准的C编译器则为1        |

示例：
```c
printf("当前文件：%s\n", __FILE__);
printf("当前行号：%d\n", __LINE__);
printf("当前函数：%s\n", __func__); // C99 [3]
```

### 防止头文件重复包含

防止同一个头文件多次包含导致重复定义的问题。
```c
#ifndef HEADER_NAME_H
#define HEADER_NAME_H

// 文件内容...

#endif // HEADER_NAME_H
```

> 替代方案：使用编译器指令 `#pragma once`（非标准，依赖于编译器实现）
```c
#pragma once
```

### \#undef 预处理指令

用于取消已定义的宏定义 [3]。
```c
#undef 宏名    // 取消宏定义
```
例如，取消宏 PI 的定义：
```c
#undef PI
```

> **注意**：不能取消由编译选项 `-D` 定义的宏 [2]。

### 示例：计算矩形周长的宏定义
```c
#define RECT_PERIMETER(a, b) (2 * (a + b))

int main() {
    printf("矩形周长: %d\n", RECT_PERIMETER(5, 3));
    return 0;
}
```
