## 文件I/O系统调用概述

在 Linux 系统中，所有 I/O 操作（包括磁盘文件、管道、设备等）都通过**文件描述符 (file descriptor)** 实现。文件描述符是一个非负整数，表示打开文件在内核中的唯一标识。

低层文件 I/O 是指不经过标准库缓冲的原生系统调用，例如：`open`, `read`, `write`, `lseek`, `close` 等。

---

## open 函数 —— 打开或创建文件

```c
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>

int open(const char *pathname, int flags);
int open(const char *pathname, int flags, mode_t mode);
```

### 参数说明：
- `pathname`: 要打开的文件路径名。
- `flags`: 访问模式和控制标志的组合（按位或 | 进行组合）。
- `mode`: 当使用 `O_CREAT` 标志创建新文件时需要指定权限位。

### flag 常见选项详解：

#### 必选访问模式（三选一）：
| 标志         | 含义                 |
|--------------|----------------------|
| `O_RDONLY`   | 只读模式             |
| `O_WRONLY`   | 只写模式             |
| `O_RDWR`     | 读写模式             |

#### 可选创建和状态标志（可组合）：
| 标志          | 含义                               |
|---------------|------------------------------------|
| `O_CREAT`     | 文件不存在则创建                  |
| `O_EXCL`      | 配合 `O_CREAT` 使用，文件已存在则失败 |
| `O_TRUNC`     | 若文件存在且为普通文件，则截断为 0 |
| `O_APPEND`    | 每次写操作前定位到文件末尾        |
| `O_NONBLOCK`  | 非阻塞模式                         |
| `O_SYNC`      | 同步写入（包括数据和元数据）       |
| `O_DSYNC`     | 只同步数据内容                    |
| `O_CLOEXEC`   | 在 exec 时自动关闭该文件描述符     |
| `O_NOFOLLOW`  | 不跟随符号链接                     |
| `O_DIRECT`    | 绕过内核缓存进行直接 I/O           |
| `O_NOATIME`   | 不更新文件的最后访问时间戳         |

### mode 模式参数（O_CREAT时必需）

常用的权限掩码（八进制）：
- `0644`: owner 可读写，group 和 others 只读
- `0755`: owner 可执行并管理，group/others 只能执行读取
- 实际创建文件的权限：`mode & ~umask`

### 示例代码：
```c
#include <fcntl.h>
#include <stdio.h>
#include <unistd.h>
#include <sys/stat.h>

int main() {
    int fd = open("example.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (fd == -1) {
        perror("open failed");
        return 1;
    }
    printf("File opened with fd: %d\n", fd);
    close(fd);
    return 0;
}
```

## close 函数 —— 关闭一个打开的文件描述符

```c
#include <unistd.h>
int close(int fd);
```

作用是释放与文件描述符对应的资源（如 inode、缓冲区、索引节点等），关闭后不能再对 fd 进行读写操作。

### 返回值：
- 成功返回 0；
- 失败返回 -1（设置 errno）

### 示例代码：
```c
int fd = open("file.txt", O_RDONLY);
if (fd != -1) {
    // ... do something ...
    close(fd);   // 必须显式关闭
}
```

## read 函数 —— 从文件描述符读取数据

```c
#include <unistd.h>
ssize_t read(int fd, void *buf, size_t count);
```

将最多 `count` 字节的数据从文件描述符 `fd` 中读入缓冲区 `buf`。

### 返回值：
- 正常：实际读取的字节数；
- EOF: 返回 0；
- 出错：返回 -1 并设置 `errno`

### 示例代码：
```c
char buffer[1024];
int fd = open("test.txt", O_RDONLY);
if (fd == -1) {
    perror("Failed to open");
    return 1;
}

ssize_t bytes_read = read(fd, buffer, sizeof(buffer) - 1);
if (bytes_read > 0) {
    buffer[bytes_read] = '\0';  // null-terminate string
    printf("Read %zd bytes: %s\n", bytes_read, buffer);
}
close(fd);
```

## write 函数 —— 向文件描述符写入数据

```c
#include <unistd.h>
ssize_t write(int fd, const void *buf, size_t count);
```

将最多 `count` 字节的数据从 `buf` 写入文件描述符 `fd`。

### 返回值：
- 写入成功的字节数；
- 错误返回 -1。

### 示例代码：
```c
const char *data = "Hello, world!\n";
int fd = open("output.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
if (fd == -1) {
    perror("Failed to open");
    return 1;
}

ssize_t bytes_written = write(fd, data, strlen(data));
if (bytes_written == -1) {
    perror("Write failed");
} else {
    printf("Successfully wrote %zd bytes.\n", bytes_written);
}
close(fd);
```

## lseek 函数 —— 移动文件指针位置

```c
#include <sys/types.h>
#include <unistd.h>

off_t lseek(int fd, off_t offset, int whence);
```

改变当前文件描述符的偏移量，支持三种基准点：

| whence     | 含义            | offset 解释             |
|------------|------------------|--------------------------|
| `SEEK_SET` | 文件开始         | 从起始偏移量为 offset   |
| `SEEK_CUR` | 当前文件偏移位置 | 从当前位置加上 offset   |
| `SEEK_END` | 文件结尾         | 从结尾位置加 offset     |

注意：并非所有文件都允许 lseek（例如管道、终端等）

### 示例代码：
```c
// 移动到文件开头
lseek(fd, 0, SEEK_SET);

// 获取当前文件偏移位置
off_t pos = lseek(fd, 0, SEEK_CUR);
printf("Current file position: %ld\n", pos);

// 移动到文件末尾
lseek(fd, 0, SEEK_END);
```

## creat 函数 —— 简化版的 open

```c
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>

int creat(const char *pathname, mode_t mode);
```

等效于调用：

```c
open(pathname, O_WRONLY | O_CREAT | O_TRUNC, mode);
```

主要用于简化“只写”+“创建且清空”的操作流程。

### 示例代码：
```c
int fd = creat("simple.txt", 0644);
if (fd != -1) {
    const char *msg = "Created by creat().\n";
    write(fd, msg, strlen(msg));
    close(fd);
}
```

## 总结表格对比

| 函数       | 功能                 | 特点                         |
|------------|----------------------|------------------------------|
| `open()`   | 打开或创建文件       | 支持多种标志控制行为        |
| `close()`  | 关闭已打开的文件     | 必须显式调用防止资源泄漏    |
| `read()`   | 从文件读数据         | 返回字节数，可能部分读取    |
| `write()`  | 向文件写数据         | 类似 read，也可能部分写入   |
| `lseek()`  | 改变文件偏移量       | 并非所有文件都支持          |
| `creat()`  | 创建只写新文件       | 简化的 open 行为            |
