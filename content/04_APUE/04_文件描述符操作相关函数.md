## 文件描述符操作相关函数

### dup/dup2函数

文件描述符是操作系统用来管理和跟踪打开文件或设备的抽象。`dup` 和 `dup2` 函数用于复制现有文件描述符。

```c
#include <unistd.h>

// 复制文件描述符，返回最小可用文件描述符
int dup(int oldfd);

// 复制文件描述符到指定文件描述符
int dup2(int oldfd, int newfd);

// Linux特有，复制文件描述符并设置标志
int dup3(int oldfd, int newfd, int flags);
```

#### dup vs dup2 区别

- `dup(oldfd)`: 自动分配最小可用文件描述符。
- `dup2(oldfd, newfd)`: 复制到指定的 `newfd`。如果 `newfd` 已经是一个有效的文件描述符，则先关闭该描述符。这使得 `dup2` 在重定向标准输入 (`stdin`, `stdout`, `stderr`) 和其他需要特定描述符的操作中非常有用。

### fcntl函数

`fcntl` 函数用于对文件描述符执行控制操作。它功能强大，可以实现文件描述符的复制、标志的设置和获取等操作。

```c
#include <unistd.h>
#include <fcntl.h>

int fcntl(int fd, int cmd, ... /* arg */ );
```

#### fcntl 函数的功能

1. **复制文件描述符**: 通过 `cmd` 参数指定 `F_DUPFD` 或 `F_DUPFD_CLOEXEC` 命令，复制指定的文件描述符。
2. **获取/设置文件描述符标志**: 通过 `cmd` 参数指定 `F_GETFD` 和 `F_SETFD` 命令，来获取或设置文件描述符的标志。
3. **获取/设置文件状态标志**: 使用 `F_GETFL` 和 `F_SETFL` 命令，可以获取或设置文件的状态标志，例如文件能否被读写、是否是非阻塞模式等。
4. **获取/设置异步 I/O 所有权**: 通过 `F_GETOWN` 和 `F_SETOWN` 命令，管理异步 I/O 的通知。
5. **获取/设置记录锁**: 使用 `F_GETLK`、`F_SETLK` 和 `F_SETLKW` 命令，实现文件的锁定机制，防止多个进程同时写入同一个文件区域，造成数据不一致性。

#### 常见的 fcntl 命令

- `F_DUPFD`: 返回一个新的文件描述符，该描述符值大于或等于 `arg`，并且指向与 `fd` 相同的文件表项。新的文件描述符继承了旧描述符的标志。
- `F_GETFD`: 获取文件描述符的标志。返回的标志是 `FD_CLOEXEC`，表示该描述符是否在进程执行 `exec()` 系统调用时会被自动关闭。
- `F_SETFD`: 设置文件描述符的标志。`arg` 通常是 `FD_CLOEXEC` 或 `0`。
- `F_GETFL`: 获取文件描述符的文件状态标志。
  - `O_RDONLY` 表示文件以只读形式打开。
  - `O_WRONLY` 表示文件以只写形式。
  - `O_RDWR` 表示文件可以读写。
  - `O_NONBLOCK` 设置非阻塞模式，对 `read()` 或 `write()` 调用立即返回，而不是等待资源成为可用。
- `F_SETFL`: 设置文件描述符的文件状态标志。
- `F_GETLK`: 获取指定文件中某个区域上的锁的信息。
- `F_SETLK`: 对一个文件区域施加一个锁，或释放一个锁。如果锁不能立即设置，调用将失败并返回 `-1`。
- `F_SETLKW`: 类似于 `F_SETLK`，但在无法获取锁时，调用将阻塞，直到可以成功地获取锁或发生错误。
