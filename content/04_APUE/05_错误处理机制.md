## 错误处理机制

在嵌入式系统编程中，妥善地处理错误是保证系统稳定性和可靠性的关键。合理的错误处理机制不仅可以提供有用的调试信息，还可以帮助系统恢复或优雅地退出。以下是几种常见的错误处理机制及其使用方法。

### errno全局变量

`errno` 是一个全局整数变量，用于报告大多数系统调用和标准库函数出错时产生的错误类型。它由`<errno.h>`头文件定义，并且其值在每次出错后被设置。

```c
#include <errno.h>
extern int errno;  // 全局错误变量
```

**使用示例：**

```c
#include <stdio.h>
#include <errno.h>
#include <fcntl.h>

int main() {
    int fd = open("/nonexistent_file", O_RDWR);
    if (fd == -1) {
        printf("Failed to open file. Error: %d\n", errno);
    }

    // 清除errno以便后续使用
    errno = 0;
    return 0;
}
```

### perror函数

`perror`函数用于打印与当前`errno`值相对应的标准错误消息，前缀为指定字符串。其原型如：

```c
#include <stdio.h>
void perror(const char *s);  // 打印错误信息
```

**使用示例：**

```c
#include <stdio.h>
#include <fcntl.h>

int main() {
    int fd = open("/nonexistent_file", O_RDWR);
    if (fd == -1) {
        perror("open failed");  // 输出类似于："open failed: No such file or directory"
    }
    return 0;
}
```

### strerror函数

`strerror`函数用于将错误码转换为人类可读的错误描述字符串。其签名如下：

```c
#include <string.h>
char *strerror(int errnum);  // 错误码转字符串
```

**使用示例：**

```c
#include <stdio.h>
#include <errno.h>
#include <fcntl.h>
#include <string.h>

int main() {
    int fd = open("/nonexistent_file", O_RDWR);
    if (fd == -1) {
        const char* error_description = strerror(errno);
        printf("Failed to open file. Error description: %s\n", error_description);
    }
    return 0;
}
```

### 自定义错误处理函数

在某些情况下，标准库提供的错误处理工具可能无法满足特定的需求。因此，可以编写自定义的错误处理函数来记录错误日志、发送通知或进行其他动作。

```c
#include <stdio.h>
#include <errno.h>
#include <string.h>

void custom_error_handling(const char* func_name, const char* file_name, int line_number) {
    fprintf(stderr, "[%s:%d] %s: %s\n",
            file_name, line_number, func_name, strerror(errno));
}

// 在你的代码中使用这个函数
#define HANDLE_ERROR() custom_error_handling(__func__, __FILE__, __LINE__)
```

**使用示例：**

```c
#include <stdio.h>
#include <fcntl.h>
#include "custom_error_handler.h"

int main() {
    int fd = open("/nonexistent_file", O_RDWR);
    if (fd == -1) {
        HANDLE_ERROR();  // 输出类似于："main: custom_error_test.c:12: open: No such file or directory"
    }
    return 0;
}
```

### 注意事项

- `errno` 的状态在许多库函数调用后会被改变，因此在检查 `errno` 之前需要确认没有任何中间调用改变它的值。
- 多线程环境中，每个线程应该有自己独立的`errno`副本以避免冲突。
- 避免在多线程程序中直接使用`perror`, 因为其输出是不安全的；可以使用`strerror_r`代替来生成线程安全的错误描述。
