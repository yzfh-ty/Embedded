## 目录操作函数

在Linux/Unix系统中，目录操作是文件系统编程的基础。目录操作函数用于创建、删除、遍历和管理目录结构。

### mkdir函数 - 创建目录

#### 函数原型
```c
#include <sys/stat.h>
#include <sys/types.h>

int mkdir(const char *pathname, mode_t mode);
```

#### 参数说明
- **pathname**: 要创建的目录路径名（可以是相对路径或绝对路径）
- **mode**: 目录的访问权限模式

#### 返回值
- 成功：返回0
- 失败：返回-1，并设置errno错误码

#### 权限模式详解
```c
// 常用权限模式常量
#define S_IRWXU 00700    // 文件所有者读、写、执行权限
#define S_IRUSR 00400    // 文件所有者读权限
#define S_IWUSR 00200    // 文件所有者写权限
#define S_IXUSR 00100    // 文件所有者执行权限

#define S_IRWXG 00070    // 组用户读、写、执行权限
#define S_IRGRP 00040    // 组用户读权限
#define S_IWGRP 00020    // 组用户写权限
#define S_IXGRP 00010    // 组用户执行权限

#define S_IRWXO 00007    // 其他用户读、写、执行权限
#define S_IROTH 00004    // 其他用户读权限
#define S_IWOTH 00002    // 其他用户写权限
#define S_IXOTH 00001    // 其他用户执行权限

// 特殊权限位
#define S_ISUID 04000    // 设置用户ID位
#define S_ISGID 02000    // 设置组ID位
#define S_ISVTX 01000    // 粘滞位
```

#### 使用示例
```c
#include <stdio.h>
#include <sys/stat.h>
#include <sys/types.h>
#include <unistd.h>
#include <errno.h>
#include <string.h>

int main() {
    // 创建权限为755的目录（rwxr-xr-x）
    if (mkdir("test_dir", 0755) == -1) {
        perror("mkdir failed");
        printf("Error: %s\n", strerror(errno));
        return 1;
    }
    printf("Directory 'test_dir' created successfully\n");
  
    // 创建多级目录需要逐级创建
    if (mkdir("parent", 0755) == 0) {
        if (mkdir("parent/child", 0755) == 0) {
            printf("Nested directory created\n");
        }
    }
  
    return 0;
}
```

#### 常见错误码
- **EACCES**: 父目录权限不足
- **EEXIST**: 目录已存在
- **ENOENT**: 父目录不存在
- **ENOSPC**: 磁盘空间不足
- **EROFS**: 文件系统只读

### rmdir函数 - 删除空目录

#### 函数原型
```c
#include <unistd.h>

int rmdir(const char *pathname);
```

#### 参数说明
- **pathname**: 要删除的目录路径名

#### 返回值
- 成功：返回0
- 失败：返回-1，并设置errno错误码

#### 重要限制
1. **只能删除空目录** - 目录必须不包含任何文件或其他子目录
2. **不能删除当前工作目录**
3. **目录必须存在**

#### 使用示例
```c
#include <stdio.h>
#include <unistd.h>
#include <errno.h>
#include <string.h>

int main() {
    // 删除空目录
    if (rmdir("empty_dir") == -1) {
        switch (errno) {
            case ENOTEMPTY:
                printf("Directory is not empty\n");
                break;
            case EACCES:
                printf("Permission denied\n");
                break;
            case ENOENT:
                printf("Directory does not exist\n");
                break;
            default:
                printf("rmdir failed: %s\n", strerror(errno));
        }
        return 1;
    }
    printf("Directory removed successfully\n");
  
    return 0;
}
```

#### 常见错误码
- **EACCES**: 权限不足
- **EBUSY**: 目录正在被使用
- **EINVAL**: 路径名无效
- **ENOTEMPTY**: 目录非空
- **ENOENT**: 目录不存在
- **EROFS**: 文件系统只读

### 扩展目录操作函数

#### opendir, readdir, closedir - 目录遍历

```c
#include <dirent.h>

DIR *opendir(const char *name);           // 打开目录
struct dirent *readdir(DIR *dirp);        // 读取目录项
int closedir(DIR *dirp);                  // 关闭目录
```

#### 使用示例 - 列出目录内容
```c
#include <stdio.h>
#include <dirent.h>
#include <errno.h>
#include <string.h>

void list_directory(const char *path) {
    DIR *dir;
    struct dirent *entry;
  
    dir = opendir(path);
    if (dir == NULL) {
        printf("Cannot open directory '%s': %s\n", path, strerror(errno));
        return;
    }
  
    printf("Contents of directory '%s':\n", path);
    while ((entry = readdir(dir)) != NULL) {
        printf("%s\n", entry->d_name);
    }
  
    closedir(dir);
}

int main() {
    list_directory(".");
    return 0;
}
```

#### chmod - 修改目录权限
```c
#include <sys/stat.h>

int chmod(const char *pathname, mode_t mode);
```

#### getcwd, chdir - 获取和改变当前工作目录
```c
#include <unistd.h>

char *getcwd(char *buf, size_t size);     // 获取当前工作目录
int chdir(const char *path);              // 改变当前工作目录
```

// 检查目录是否为空
int is_directory_empty(const char *path) {
    DIR *dir;
    struct dirent *entry;
    int count = 0;
  
    dir = opendir(path);
    if (dir == NULL) {
        return -1; // 错误

// 安全删除目录（仅删除空目录）
int safe_rmdir(const char *path) {
    int result = is_directory_empty(path);
    if (result == 1) {
        return rmdir(path);
    } else if (result == 0) {
        errno = ENOTEMPTY;
        return -1;
    } else {
        return -1;
    }
}
