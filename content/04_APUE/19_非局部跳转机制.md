## 非局部跳转机制

### `setjmp(3)` / `longjmp(3)`

用于异常处理或深层嵌套函数中的错误返回。

```c
#include <setjmp.h>
jmp_buf env;
int setjmp(jmp_buf env);  // 返回值为 0，表示设置成功
void longjmp(jmp_buf env, int val);  // 非局部跳转返回
```

#### 示例

```c
#include <stdio.h>
#include <setjmp.h>

jmp_buf env;

void func3() {
    printf("进入func3\n");
    longjmp(env, 42);  // 跳回 setjmp，并返回 42
}

void func2() {
    func3();
}

void func1() {
    func2();
}

int main() {
    int val = setjmp(env);
    if (val == 0) {
        printf("首次调用 setjmp\n");
        func1();
    } else {
        printf("longjmp 返回值为: %d\n", val);
    }
    return 0;
}
```
