## 函数指针与回调机制

### 函数指针的基础知识

函数名本身是函数的入口地址（指针）。

```c
void func(const char *);
void (*p)(const char *) = func;
p("Hello"); // 等效调用 func("Hello")
```

#### 示例（函数指针数组模拟命令调用）：

```c
void sayhello(const char * name) { printf("你好: %s\n", name); }
void saygoodbye(const char * name) { printf("再见: %s\n", name); }

typedef void (*MYFUNP)(const char *);

int main(void) {
    MYFUNP pfun[2] = {sayhello, saygoodbye};
    for (int i = 0; i < 2; i++) {
        pfun[i]("张三");
    }
    return 0;
}
```
