## 系统资源限制管理

### 系统工具：`ulimit`

```shell
ulimit -a     # 查看当前限制
ulimit -n 1024 # 设置文件描述符最大值
```

### `getrlimit()` 和 `setrlimit()`

```c
#include <sys/resource.h>
int getrlimit(int resource, struct rlimit *rlim);
int setrlimit(int resource, const struct rlimit *rlim);

struct rlimit {
    rlim_t rlim_cur; /* 软限制，当前生效的值 */
    rlim_t rlim_max; /* 硬限制，最大可设置为该值 */
};
```

#### 支持的 `resource`：

| resource         | 含义           |
| ---------------- | ------------ |
| `RLIMIT_NOFILE`  | 最大打开文件数      |
| `RLIMIT_CORE`    | core dump 大小 |
| `RLIMIT_CPU`     | CPU 使用时间     |
| `RLIMIT_DATA`    | 数据段大小        |
| `RLIMIT_FSIZE`   | 最大文件大小       |
| `RLIMIT_STACK`   | 允许的最大栈大小     |
| `RLIMIT_MEMLOCK` | 锁定内存大小       |
| `RLIMIT_NPROC`   | 每个用户最大子进程数   |
| `RLIMIT_RSS`     | 最大物理内存驻留值    |
| `RLIMIT_AS`      | 虚拟内存大小       |

#### 示例代码

```c
#include <stdio.h>
#include <sys/resource.h>

int main() {
    struct rlimit rl;
    getrlimit(RLIMIT_NOFILE, &rl);
    printf("当前最大文件描述符数：%ld (最大 %ld)\n", (long)rl.rlim_cur, (long)rl.rlim_max);

    rl.rlim_cur = 2048;
    rl.rlim_max = 4096;
    if (setrlimit(RLIMIT_NOFILE, &rl) == 0) {
        printf("设置成功\n");
    } else {
        perror("setrlimit");
    }
    return 0;
}
```
