## 编译

编译是指将 C 语言代码转化为 CPU 能够执行的数据和指令的过程。

### 命令

命令格式

```shell
gcc [选项]  文件1.c 文件2.c ...
```

运行

```shell
./a.out
```

常用选项

|   选项    |       说明        |
| :-----: | :-------------: |
| -o <路径> | 指定输出路径，代替a.out  |
|   -g    | 加入调试信息（用于GDB调试） |
| -I <路径> |    指定头文件的路径     |
| -l<库名>  |     指定库文件名称     |
|   -E    |    仅需处理，不编译     |
|   -S    |     编译，不汇编      |
|   -c    |   编译和汇编，但不连接    |
|  -Wall  |     报告所有警告      |

### C 语言编译的步骤:

1. 预处理 *gcc -E xxx.c*

```shell
gcc -E hello.c
```

1. 编译 gcc -S

```shell
gcc -S hello.c # 生成 hello.S 
```

1. 编译并汇编 gcc -c

```shell
gcc -c hello.S   # 生成 hello.o
```

1. 链接 *gcc -o a.out xxx.o yyy.o*

```shell
gcc -o hello hello.o  # 生成 hello
```


## 第一个hello world! 程序

文件名: hello.c

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{
	printf("hello world!\n");
	return 0;
}
```

编译:

```shell
gcc -o hello hello.c
```

运行:

```shell
./hello
```

说明:

- *# include <文件名.h>* 预处理包头文件
- 第一个 *int* 是 main 函数的返回的数据类型。
- *main* 是一个函数名，main 是程序的主入口函数。
- *(int argc, char * argv[])* 是 main 函数的参数列表。
- *{}* 包含内部的语句是main 的函数体部分。
- *pirntf();* 打印数据到终端.
- *"hello world!\n"* 打印的文字（是字符串）。*\n* 表示换行。
- *return 0;* 是返回函数, 返回值是零.
