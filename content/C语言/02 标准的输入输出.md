# printf函数

作用：打印字符数据到标准输出。

头文件：*# include <stdio.h>*

调用格式:

```c
printf("格式化字符串", 表达式1, 表达式2, ...);
```

格式化字符串的占位符和类型码

|占位符|说明|
|---|---|
|%d|将数字转为有符号十进制整数|
|%i|同 %d 功能一致|
|%u|将数字转为无符号十进制整数|
|%o|八进制整数|
|%x|十六进制整数|
|%f|小数（默认保留小数点后六位）|
|%e/%E|指数显示小数|
|%g|自动转换小数和指数，E小写|
|%G|自动转换小数和指数，E大写|
|%%|表示一个百分号|
|%s|字符串|
|%p|指针|

长度修饰符

| 修饰符  | 说明                                       |
| ---- | ---------------------------------------- |
| %ld  | 用于 long int或 unsigned long int           |
| %lld | 用于 long long int或 unsigned long long int |
| %Lf  | 用于 long double                           |

示例：

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	float pi = 3141592653.589793;    
	int x = 8141244;    
	long long int lli= 1000;    
	
	printf("---%d---\n", x); // ---8141244---    
	printf("---%u---\n", x); // ---8141244---    
	printf("---%i---\n", x); // ---8141244---    
	printf("---%o---\n", x); // ---37034674---    
	printf("---%x---\n", x); // ---7c39bc---    
	printf("---%f---\n", pi); // ---3141592576.000000---    
	printf("---%e---\n", pi); // ---3.141593e+09---    
	printf("---%g---\n", pi); // ---3.14159e+09---    
	printf("---%G---\n", pi); // ---3.14159E+09---    
	printf("---%lld---\n", lli); // ---1000---    
	
	return 0;
}
```

# scanf 函数

作用：从终端读取数据，放入对应的变量中。

头文件：*# include <stdio.h>*

调用格式:

```c
scanf("读取格式字符串", 变量地址1, 变量地址2...);
```

常用读取格式

|占位符|说明|
|---|---|
|%d|读取十进制整数|
|%s|读取字符串|
|%f|读取小数|

取地址运算符 **&**

所用：返回变量的内存地址。

用法：

```c
& 变量
```

示例：

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	int x = 1; //    
	
	printf("---%p---\n", &x); // ---0x7ffc5c932b34---    
	printf("之前的x:%d\n", x);    
	scanf("%d", &x);    
	printf("读取之后的x:%d\n", x);    
	
	return 0;
}
