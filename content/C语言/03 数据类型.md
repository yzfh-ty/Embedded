# C11 标准的基础数据类型

## 整数无符号数据类型

|数据类型|字节数|说明|
|---|---|---|
|unsigned char|1|0~255|
|unsigned short int|2|0~65535|
|unsigned int|4|0~4294967296|
|unsigned long int|4及以上|...|
|unsigned long long int|8及以上|...|

## 整数有符号数据类型

| 数据类型                 | 字节数  | 范围                     |
| -------------------- | ---- | ---------------------- |
| signed char          | 1    | -128~127               |
| signed short int     | 2    | -32768~32767           |
| signed int           | 4    | -2147483648~2147483647 |
| signed long int      | 4及以上 | ...                    |
| signed long long int | 8及以上 | ...                    |

> *signed* 关键字可以省略不写

## 小数的数据类型

| 数据类型        | 字节数 | 范围            |
| ----------- | --- | ------------- |
| float       | 4   | 1.25=0.75*2^1 |
| double      | 8   |               |
| long double | 16  |               |
## 布尔值 （bool）

使用时需要导入 *stdbool.h* 头文件

C 语言中的布尔值：

真（True）: 非零值

假（False）：零值(0)
