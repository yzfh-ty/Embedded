# 运算符

运算符是表示运算规则的符号。

算数运算符

```c
+    加法
-    减法
*    乘法
/    除法
%    求余数（取模）运算（不能用于浮点数运算）
```

赋值表达式

```c
变量名 = 表达式
```

复合赋值运算表达式

```c
变量 += 表达式     // 等同于:  变量 = 变量 + 表达式
变量 -= 表达式     // 等同于:  变量 = 变量 - 表达式
变量 *= 表达式     // 等同于:  变量 = 变量 * 表达式
变量 /= 表达式     // 等同于:  变量 = 变量 / 表达式
变量 %= 表达式     // 等同于:  变量 = 变量 % 表达式
# 以下是位运算相关
变量 &= 表达式     // 等同于:  变量 = 变量 & 表达式
变量 |= 表达式     // 等同于:  变量 = 变量 | 表达式
变量 ^= 表达式     // 等同于:  变量 = 变量 ^ 表达式
变量 <<= 表达式    // 等同于:  变量 = 变量 << 表达式
变量 >>= 表达式    // 等同于:  变量 = 变量 >> 表达式
```

示例

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	int x = 7,y = 2;     
	int result;        
	
	result = x + y; // 赋值语句 result = 9    
	// result = result + 5;    
	result += 5;    
	
	printf("%d\n", result);    
	
	return 0;
}
```

## 整数自增自减运算符

运算符  ++ 、  --

语法:

1. 先变化再返回值。
    
    ++ 变量名 -- 变量名
    
2. 先返回值再变化。
    
    变量名++ 变量名--
    

示例

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	int x = 7;    
	int y;     // 自增运算    
	
	// y = x++;  //x先返回值再自身++    
	y = ++x;  //x自身++后再返回值    
	printf("x:%d, y:%d\n", x, y);    
	
	return 0;
}
```

## 逻辑运算

三种:

- 与运算(and) ，运算符: *&&*
- 或运算(or)， 或运算: *||*
- 非(not)，运算符: *!*

### 与运算（*&&*）

- 两者都成立，结果才成立，只要有一个不成立，结果就为假。

示例

```c
int score = 70;
score >= 60 && score <= 100 
```

### 或运算（*||*）

两者只要有一个为真，结果就为真，两者都为假，结果才为假

### 非运算（*!*）

逻辑取反（非），假变真，真变假。

表达式

```C
!表达式
```

## 一元运算符

示例

```c
#include <stdio.h>  
  
int main(int argc, char * argv[]) {  
  
    printf("与运算 &&\n");  
    printf("1 && 1 = %d\n", 1 && 1);  
    printf("100 && 0 = %d\n", 100 && 0);  
    printf("0 && 1 = %d\n", 0 && 1);  
    printf("0 && 0 = %d\n", 0 && 0);  
  
    printf("或运算 ||\n");  
    printf("1 || 1 = %d\n", 1 || 1);  
    printf("100 || 0 = %d\n", 100 || 0);  
    printf("0 || 1 = %d\n", 0 || 1);  
    printf("0 || 0 = %d\n", 0 || 0);  
  
    printf("非运算: !\n");  
    printf("!1 = %d\n", !1);  
    printf("!0 = %d\n", !0);  
    printf("!100 = %d\n", !100);  
    printf("!!100 = %d\n", !!100);  
  
    return 0;  
}
```

## sizeof() 运算符求 内存长度计算

作用：用来返回一个数据（变量或常量）所占的内存长度。

示例

```c
#include <stdio.h>  

int main(int argc, char * argv[]) {  

    char c;  

    unsigned char c2;  

    short s;  

    int x;  

    unsigned long int lx;  

    long long int llx;  

    printf("sizeof(c):%zu\n", sizeof(c)); // 1  

    printf("sizeof(c2):%zu\n", sizeof(c2)); // 1  

    printf("sizeof(s):%zu\n", sizeof(s)); // 2  

    printf("sizeof(x):%zu\n", sizeof(x)); // 4  

    printf("sizeof(lx):%zu\n", sizeof(lx)); // 4  

    printf("sizeof(llx):%zu\n", sizeof(llx)); // 8  

    printf("sizeof('A'):%zu\n", sizeof('A')); // 4  

    printf("sizeof(100):%zu\n", sizeof(100)); // 4  

    printf("sizeof(100L):%zu\n", sizeof(100L)); // 8  

    printf("sizeof(100LL):%zu\n", sizeof(100LL)); // 8  

    return 0;  

}
```
