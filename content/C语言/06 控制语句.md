# 选择语句（也叫分支语句）

选择语句的种类：

- if (表达式) 语句
- if (表达式) 语句1 else 语句2
- switch (表达式) 语句

## if 语句

作用：根据条件表达式的值来选择性的执行语句。

语法格式：

```c
if (表达式) 语句1或if (表达式) 语句1 else 语句2
```

> if 和 else 是关键字。

示例：

写一个程序，输入一个正整数，打印出这个整数是**奇数**还是**偶数。**

奇数：不能被 2整除的数，如：1 3 5 7。

偶数：能被 2整除的数，如：2 4 6 8 0。

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	unsigned int number;    
	
	printf("请输入整数：");    
	scanf("%d", &number);        
	
	if (number % 2 == 1)         
		printf("%d 是奇数\n", number);    
	else        
		printf("%d 是偶数\n", number);    
		
	return 0;
}
```

练习1：

写一个程序，输入你的年龄，如果年龄大于 18 岁，显示 您可以申请入党。否则什么都不做。

参考答案：

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	int age;     
	
	printf("请输入年龄：");    
	scanf("%d", &age);        
	
	if (age >= 18)               
		printf("您可以申请入党\n");    
	
	return 0;
}
```

练习2：

改写上一个程序，输入你的年龄，如果年龄大于 18 岁，显示您可以申请入党。否则提示您还没长大，请好好学习

参考答案：

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	int age;    
	
	printf("请输入年龄：");    
	scanf("%d", &age);        
	
	if (age >= 18)         
		printf("您可以申请入党\n");    
	else

}
```

## 语句

语句是计算机执行的最小单位。

语句的两种写法：

1. 表达式后加分号，如:x = 100;
    
2. 使用 大括号 {}，内部可以写入0~多条语句成为一条语句。
    
    - 如: {x = 100; x ++; printf("%d\n", x);}

if 语句嵌套实现多分支结构

```c
if (表达式) 语句1
// 或
if (表达式) 语句1 else 语句2
// 扩展应用
if (表达式) 
{    
	语句1
} else if (表达式) 
{    
	语句2 
} else if (表达式) 
{    
	语句3
} else 
{    
	语句4
}
```
