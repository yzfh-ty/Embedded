# 选择语句（也叫分支语句）

选择语句的种类：

- if (表达式) 语句
- if (表达式) 语句1 else 语句2
- switch (表达式) 语句

## if 语句

作用：根据条件表达式的值来选择性的执行语句。

语法格式：

```c
if (表达式) 语句1或if (表达式) 语句1 else 语句2
```

> if 和 else 是关键字。

示例：

写一个程序，输入一个正整数，打印出这个整数是**奇数**还是**偶数。**

奇数：不能被 2整除的数，如：1 3 5 7。

偶数：能被 2整除的数，如：2 4 6 8 0。

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	unsigned int number;    
	
	printf("请输入整数：");    
	scanf("%d", &number);        
	
	if (number % 2 == 1)         
		printf("%d 是奇数\n", number);    
	else        
		printf("%d 是偶数\n", number);    
		
	return 0;
}
```

练习1：

写一个程序，输入你的年龄，如果年龄大于 18 岁，显示 您可以申请入党。否则什么都不做。

参考答案：

```c
#include <stdio.h>
int main(int argc, char * argv[]) 
{    
	int age;     
	
	printf("请输入年龄：");

}
```

## 语句

语句是计算机执行的最小单位。

语句的两种写法：

1. 表达式后加分号，如:x = 100;
    
2. 使用 大括号 {}，内部可以写入0~多条语句成为一条语句。
    
    - 如: {x = 100; x ++; printf("%d\n", x);}

if 语句嵌套实现多分支结构

```c
if (表达式) 语句1
// 或
if (表达式) 语句1 else 语句2
// 扩展应用
if (表达式) 
{    
	语句1
} else if (表达式) 
{    
	语句2 
} else if (表达式) 
{    
	语句3
} else 
{    
	语句4
}
```


练习：

写一个程序，输入年龄：

如果年龄小于 8 岁，打印“儿童”；

如果年龄大于8岁小于18岁，打印“少年”，

如果年龄大于18岁小于40岁，打印“青年”，

如果年龄大于40岁小于60岁，打印“中年”，

如果年龄大于60岁，打印“中老年”。

参考答案

```c
#include <stdio.h>  
  
int main(int argc, char * argv[]) {  
    int age;  
  
    printf("请输入年龄：");  
    scanf("%d", &age);  
  
    // 如果年龄小于 8 岁，打印“儿童”；  
    if (age < 8) {  
        printf("儿童\n");  
    } else if (age < 18) {  
        // 如果年龄大于8岁小于18岁，打印“少年”，  
        printf("少年\n");  
    } else if (age < 40) {  
        // 如果年龄大于18岁小于40岁，打印“青年”，  
        printf("青年\n");  
    } else if (age < 60) {  
        // 如果年龄大于40岁小于60岁，打印“中年”，  
        printf("中年\n");  
    } else {  
        // 如果年龄大于60岁，打印“中老年”。  
        printf("中老年\n");  
    }  
    return 0;  
}
```

## switch 语句

作用：根据表达式具体的取值，执行对应的语句（语句块）。

语法：

```c
switch (表达式) 
{    
	case 常量值1: 语句块1;    
	case 常量值2: 语句块2;    
	case 常量值3: 语句块3;    
	...     
	default: 语句块other;
}
```

语法说明：

- switch 语句先计算 表达式的值，然后用此值自上而下比较 case 中的常数值，直至找到一个相等的值，然后执行匹配的语句块。
- 如果 此语句块内没有用 break 语句终止执行 switch,则会向下执行所有的语句块，直至结束。

**break 语句**：

作用：用于终止当前 switch、for、while、do-while语句的执行。

示例：

写一个程序，输入成绩的级别:A 级（90-100)，B级（80-89)，C级（70~79）， D级（60-69)，E 级（0-59)。输入级别，打印分数范围。

```c
#include <stdio.h>  
int main(int argc, char * argv[]) {  
   char ch;  
  
   printf("请输入一个字符:");  
   scanf("%c", &ch);  // A 或 a  
   switch (ch) {  
       case 'A':  
       case 'a':  
           printf("90~100\n");  
           break;  
       case 'B':  
       case 'b':  
           printf("80~89\n");  
           break;  
       case 'C':  
       case 'c':  
           printf("70~79\n");  
           break;  
       case 'D':  
       case 'd':  
           printf("60~69\n");  
           break;  
       case 'E':  
       case 'e':  
           printf("0~59\n");  
           break;  
       default: printf("您的输入有错误\n");  
   }  
}
```

# 循环语句 (Iteration statements)

C 语言中的循环语句有 3 种：

1. for 语句
2. while 语句
3. do-while语句

## for 语句

语法

```c
for (初始化表达式【1】; 条件表达式【2】; 后处理表达式【3】)    语句1【4】
```

作用：根据条件表达式重复执行语句1。

语法说明：

1. **初始化表达式**会在 for语句运行时，最先运行，且只运行一次
2. **条件表达式**然后运行，当表达式返回真值，则执行语句1，否则结束循环。
3. 当执行完语句1， 再执行 **后处理表达式**。然后跳转到条件表达式，执行第2步。

- 初始化表达式可以为空，后处理表达式可以为空，
- 条件表达式可以为空，为空时表示条件一直成立。

最简写法（条件一直成立的循环）：

```c
for (;;) {}
```

> **Ctrl + c** 可以终止正在执行的程序。

示例

打印 1~10 十个整数。

```c
#include <stdio.h>  
int main(int argc, char * argv[]) {  
    int number;  // 用于控制循环次数的变量  
  
    for (number = 1; number <= 10; number ++) {  
        printf("%d\n", number);  
    }  
    printf("number:%d\n", number); // ??? 
     
    return 0;  
}
```

练习1:

打印 1 ~ 101 之间所有的偶数。

练习2:

打印 1 ~ 100 之间所有的奇数的和。
