## 指针

### 什么是指针？

指针是用来保存另外一个变量地址的变量。

指针变量的声明方法:

```c
指向的变量的类型 * 指针变量名称1 [= 初始值1];
```

示例

```c
int i = 100;  // 声明整型变量 i,初始值为100
int j = 200;
int * p ;  // p 的类型是 int *p = &i;  // &取地址(64bit)
```

将 指针类型的变量指向某个变量

```c
指针变量名 = 变量地址：
```

指针解引用 `*`

```c
* 指针变量名 // 访问指针指向的地址。
```

说明:

- 使用指针解引用（放在表达式中），则取指向变量的值。
- 对指针解引用赋值。则修改指向的变量的值。

练习:

```
写一个程序，声明 3个 char 类型的变量 a、b、c
声明 3个 int 类型的变量 x、y、z。
a 的初始值是 65
x 的初始值是 999
1. 声明char 类型指针变量 pc1 指向 a，pc2 指向b。不使用 abc 三个变量，将 b 的值改成和 a 相同。
同样的办法将 c 的值改成 b 的值加一。
打印 a b c 的值。
2. 声明 int 类型指针变量 pi,先将其指向 x,使用 pi 修改x的值为原来的值加上一。
3. 将 pi 指向 y,使用 pi 修改y的值为666.
4. 使用 pi 指向 z ，使用 pi 直接打印 z 的值。
5. 打印 pi 和 pc1、pc2占用的内存长度:sizeof()
```

指针说明：

**不同类型的指针都是一样的，只是他指向的数据的类型不同。**

### 野指针

指向不确定位置的指针。

```c
#include <stdio.h>  
int main(int argc, char * argv[]) 
{    
	unsigned char *puc; // puc 的之不确定，叫做野指针    
	*puc = 100;    
	return 0; 
}
```

### 空指针

空指针是值为0的指针，通常写成 NULL。

含义是没有指向任何变量的指针。

如:

```c
int * p = NULL;
```

### void类型的指针

void 表示没有类型的类型。

```c
void * p = NULL; 
```

### 二级指针

二级指针：指向指针的指针（保存的是指针的地址）。
