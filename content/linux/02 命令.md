什么是命令：命令就是一个有特定功能程序。

命令的种类：

1. 内部命令（在Shell 内定义的命令）
    
    - 如： cd 、pwd

2. 外部命令（对应一个单独的文件）：
    
    - 如：tree。

命令的格式

```shell
命令 [选项]...  [参数]...
```

说明格式说明:

- 命令、选项或参数要用一个或多个空白字符（空格、制表符等人）分隔。
    
- 选项通常以 一个或两个减号开头，通常选项由命令提供，命令根据选项做不同的事情。
    
    - 如: `ls -l -a`
- 参数通常是为命令提供的数据。
    
大多数的命令参数可以写在命令的任意位置

例如：下面这两句都是正确的，但是大多数情况下我们会将参数放在命令的后面，路径或是文件放在最后面

```
ls -la /home/yzfh
ls /home/yzfh -la
```

# 系统包管理工具

## apt 命令 - [[linux/更换国内镜像源]]

作用：安装、下载、删除第三方软件。他是用于管理软件包的工具

命令格式

```shell
apt 子命令 包名
```

子命令:
``
```shell
apt update               #更新软件包索引
apt upgrade              #升级所有已经安装的软件包
apt install <包名>       #安装软件包
apt remove <包名>        #卸载软件包（不删除依赖包）
apt purge <包名>         #卸载软件包（删除依赖包）
apt list                #列出所有可以安装的软件包
apt list installed      #列出所有已经安装的软件包
apt search <关键字>      #搜索软件包
apt download <包名>      #下载软件包，不安装。
```

示例

```shell
# 看有哪些tree相关的软件包
apt search tree | grep "tree"
# 安装 tree 软件包
sudo apt install tree
# 使用 tree 命令查看 文件夹的结构
tree /etc/apttree ~tree .
# 卸载 tree 软件包
sudo apt remove tree
# 下载 tree 软件包，后续在安装
apt download tree
```

## ln 命令

作用：为文件创建硬链接或软连接。

- 硬链接：是文件的别名（不占用存储空间）
    - 文件夹不能创建硬链接。
- 软连接：是文件的快捷方式（占用存储空间）。

### 创建软链接

软链接文件内部记录的是目标文件的路径。也会占用内存空间，如果目标文件删除。则软连接文件依旧存在。但此时使用会出错。

命令格式

```shell
ln -s 源文件 目标文件
```

示例

```shell
touch ~/桌面/a.txt
ln -s ~/桌面/a.txt ./b.txt
```

### 创建硬链接

命令格式

```shell
ln 源文件 目标文件
```

示例

```shell
touch a.txt     # 创建硬链接
ln a.txt b.txt  # 为 a.txt 起了一个别名
```

# 输出重定向

- Linux 系统终端下三个重要的Input/Output。
    - 标准输入（默认是键盘）
    - 标准输出（默认是终端）
    - 标准错误输出（默认是终端）

语法

```
# 标准输出重定向到文件
命令 > 文件 
# 标准错误输出重定向到文件
命令 2> 文件 
```

示例

```shell
find /etc -name "source*" > r.txtfind /etc -name "source*" 2> error.txtfind /etc -name "source*" > r.txt 2> error.txt
```

黑洞文件：`/dev/null`

向此文件内写入任何内容都会被丢弃。


常用选项

|     选项      |                   说明                    |
| :---------: | :-------------------------------------: |
|     -m      |         创建用户主目录（通常与 *-k* 一起使用）          |
|   -s <路径>   |              指定用户登录 Shell               |
|   -c <别名>   |              为用户添加备注/描述信息               |
|   -d <路径>   |                指定用户主目录路径                |

示例:

```shell

# 创建家目录，并指定家目录的框架是 /etc/skel# 指定其主组是 emb3、别名是 zhangwuji。
# 指定 Shell 是 /bin/bash。让其加入 root、sudo 组
sudo useradd -m -k /etc/skel -g emb3 -G root,sudo -c zhangwuji -s /bin/bash zhang3 
```

## chmod 命令

作用：修改文件或文件的权限位。

```shell
rwx rwx rwx 
```

命令格式

```shell
chmod [选项] 八进制模式或 模式，模式 文件...
```

常用选项

- *-R* 递归对文件夹内部的文件进行同样的处理。

权限位 [[linux/03 文件相关的说明#文件的详细信息\|详细解释]]

```
rwx   rwx   rwx
111   111   111
 7     7     7

chmod 777 a.txt

r-x   r--   --x
101   100   001
 5     4     1

chmod 541 a.txt 
```

模式:

- *u* 表示用户权限组 user
- *g* 表示组权限 group
- *o* 表示其他 other
- *a* ugo三个组（默认）

操作：

- *+* 添加
- *-* 去掉
- *=* 设置

权限位:

- *r* 读权限
- *w* 写权限
- *x* 执行权限

```shell
rwx   r-x   rw-
 u     g     o
chmod u-r,g+w,o-w a.txt        
# 执行后-wx   rwx   r--
```

## tar 命令

作用： 将多个文件或文件夹合成一个文件（默认不压缩）。

命令格式

```shell
tar [选项...] [FILE]...
```

> tar 默认递归归档文件夹内部的文件和文件夹。

常用选项

| 选项        | 说明                     |
| --------- | ---------------------- |
| -c        | 创建归档                   |
| -x        | 还原归档文件为文件或文件夹          |
| -f <文件路径> | 指定文件                   |
| -v        | 显示归档过程                 |
| -z        | 使用 GNU Zip压缩算法进行压缩和解压缩 |
| -j        | 使用 gzip2压缩算法进行压缩和解压缩   |
| -J        | 使用 xz 压缩算法进行压缩和解压缩     |
| -C <路径>   | 解包到指定的路径               |

> tar 不压缩的包名以 *.tar* 结尾
> 
> tar 以 gzip 压缩的包名以 *.tar.gz* 或 *.tgz* 结尾
> 
> tar 以 bzip2 压缩的包名以 *.tar.bz2* 结尾
> 
> tar 以 xz 压缩的包名以 *.tar.xz* 结尾

示例

压缩示例

```shell
cp -r /etc/apt ~/testcd ~
# 打包不压缩为 test.tar 文件
tar -c -v -f test.tar test/
# 或tar -cvf test.tar test/
# 打包并用 gzip 压缩算法压缩为 test.tar.gz 文件
tar -czvf test.tar.gz test/
# 打包并用 bzip2 压缩算法压缩为 test.tar.bz2 文件
tar -cjvf test.tar.bz2 test/
# 打包并用 xz 压缩算法压缩为 test.tar.xz 文件
tar -cJvf test.tar.xz test/
```

解压缩 tar 包示例

```shell
# 解压缩不压缩的 test.tar 包 到当前路径
tar -xvf test.tar
# 解压缩不压缩的 test.tar 包 到桌面
tar -xvf test.tar -C ~/桌面/
# 解压缩 gzip 压缩的 test.tar.gz 包到当前路径
tar -xzvf test.tar.gz
# 解压缩 bz2 压缩的 test.tar.bz2 包到当前路径
tar -xjvf test.tar.bz2
# 解压缩 xz 压缩的 test.tar.xz 包到当前路径
tar -xJvf test.tar.xz
```

# 进程管理命令

什么是进程：进程是正在运行的程序

## ps 命令

作用：查看当前进程

常用选项：

| 选项   | 说明          |
| ---- | ----------- |
| -aux | 查看所有进程      |
| -ejH | 缩进现实进程的树形关系 |

*-aux* 列说明：
- USER 进程的启动者（拥有者）
- PID 进程的ID（从零开始依次递增）
- TTY 进程使用的终端
- TIME 进程使用的时间
- CMD 运行的命令
- %CPU CPU 占比
- %MEM 内存的占比
- VSZ 虚拟内存的大小
- RSS 真实内存占用大小
- STAT 进程状态
    - R 表示正在运行的进程（运行态）
    - S 表示睡眠的进程（就绪态的进程）
    - D 不可中断的睡眠进程。
    - T 表示停止态经常
    - Z 表示僵尸进程。
    - I 内核进程（Idle 闲置状态）
- START 进程启动时间
- TIME 累积占用 CPU时间

## pstree 命令

作用：以树形结构显示进程

常用选项:

- *-p* 显示 PID。

示例

```shell
pstree -p
```

## kill 命令

作用：给进程发信号，通常用于退出进程。

命令格式

```shell
kill 选项 进程号(PID)
```

常用选项

| 选项      | 说明               |
| ------- | ---------------- |
| -l      | 列出所有信号。          |
| -n      | 发送指定值的信号(n=1~64) |
| -s <名称> | 根据名称发送指定值的信号。    |

示例

```shell
kill -9 6666   # 退出 PID 为 6666 的进程
```

## ssh 命令

作用：用于远程连接，服务器端需要安装 sshd 服务。

命令格式

```shell
ssh [选项] 用户名@主机的IP地址或域名
```

示例

```
ssh easthome@192.168.33.151
```

安装 openssh-server

```shell
sudo apt install openssh-server
```

Windows 的终端

```powershell
C:\User\xxxx> powershell
PS: C:\User\xxxx> ssh easthome@192.168.33.151
```

ssh 是C/S 架构的程序

- C-Client（如:ssh命令）
- S-Server（ssh.server)

默认不支持 root 连接，需要修改配置文件 - [各个发行版修改教程](https://blog.csdn.net/crayon0/article/details/122272001)


```shell
vim /etc/ssh/sshd_config
# 找到这个 #PermitRootLogin prohibit-password  
# 在下面添加 PermitRootLogin yes

# - 需要重启系统或者sshd服务
sudo /etc/init.d/ssh stop 
sudo /etc/init.d/ssh start 
sudo service ssh restart 
```

### systemctl 命令

作用：管理各种运行于后台的服务

常用的命令格式

```shell
# 查看所有的服务（包括未运行的服务）
systemctl 

# 查看特定的服务的状态
systemctl status ssh.service

# 停止服务
systemctl stop ssh.service

# 启动服务
systemctl start ssh.service

# 重新启动服务s
ystemctl restart ssh.service

# 设置开机启动服务
systemctl enable ssh.service

# 禁止开机启动服务
systemctl disable ssh.service

# 查看是否设置开机启动服务
systemctl is-enabled ssh.service
```
