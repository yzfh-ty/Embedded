# 网络管理

### ping 命令

作用：用于检查网络链接状态。

命令格式

```
ping IP地址或域名
```

### ifconfig 命令

作用：用于查看网络配置。临时修改IP地址等。

apt 安装

```shell
sudo apt install net-tools
```

示例

```shell
# 查看所有的网络设备
ifconfig
# 查看 名为 ens33 的网络设备
ifconfig ens33
# 修改 ens33 的网络设备的 IP地址为 192.168.33.155
sudo ifconfig ens33 192.168.33.155
```

### ssh 命令

作用：用于远程连接，服务器端需要安装 sshd 服务。

命令格式

```shell
ssh [选项] 用户名@主机的IP地址或域名
```

示例

```
ssh easthome@192.168.33.151
```

安装 openssh-server

```shell
sudo apt install openssh-server
```

Windows 的终端

```powershell
C:\User\xxxx> powershell
PS: C:\User\xxxx> ssh easthome@192.168.33.151
```

ssh 是C/S 架构的程序

- C-Client（如:ssh命令）
- S-Server（ssh.server)

默认不支持 root 连接，需要修改配置文件 - [各个发行版修改教程](https://blog.csdn.net/crayon0/article/details/122272001)


```shell
vim /etc/ssh/sshd_config
# 找到这个 #PermitRootLogin prohibit-password  
# 在下面添加 PermitRootLogin yes

# - 需要重启系统或者sshd服务
sudo /etc/init.d/ssh stop 
sudo /etc/init.d/ssh start 
sudo service ssh restart 
```
